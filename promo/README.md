# Hoard's videos

The promos ([#273](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/273)) and the help videos
([#274](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/274)) are made here, and so is their music
([#291](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/291)). Nothing in them is generated by a model:
the pictures are Hoard's own screens, taken by `scripts/screenshots.py`, and shapes drawn in HTML and SVG (the Heap
as `hoard/heap.py` draws it everywhere); the music is notes written out in `music/loop.py` and synthesised there.

| | |
|---|---|
| `films/` | One file a video: its scenes, each a number of bars long, with its words in English, Japanese and Korean |
| `video/film.html` | Draws a film, one frame at a time |
| `build.py` | Takes a picture of every frame, checks it, and puts the video together with the music |
| `music/loop.py` | The music: a loop of 32 bars with no seam, and the chord a video ends on |
| `regions.json` | Things on Hoard's pages a film can point at, by name, found again in every language |
| `requirements.txt` | What these need beyond Hoard's own requirements: numpy, SciPy and Pillow, hash-checked |

## Making them

You need Hoard's requirements and these (`pip install --require-hashes -r requirements.txt -r promo/requirements.txt`),
Playwright's Chromium (`python -m playwright install chromium`), and ffmpeg.

```
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark,light --lang=en --regions=promo/regions.json
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark,light --lang=ja --regions=promo/regions.json
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark,light --lang=ko --regions=promo/regions.json
python promo/music/loop.py
python promo/build.py promo-short help-booth-signed-out --lang=en,ja,ko --shape=landscape,portrait
```

`PRODUCTS_FOLDER` is the products the website's screenshots show, the ones listed on its
[credits page](https://hoard.furryup.link/credits.html) (`scripts/export_screenshot_products.py` makes such a folder
from a library); the Media workflow in Actions takes them from `promo/products`. Only those products are shown,
with their own pictures. The videos land in `build/promo/out/`, named `hoard-<film>-<lang>-<shape>.mp4`; a film is
made only in the languages it has its words in.

`python promo/build.py FILM --preview=2,9.5,14` takes pictures of a few moments instead, to look at while writing a
film. Each frame is checked as it's drawn: a highlight or a picture that would run off the frame, or out of its window,
stops the build and says where.

## Writing a film

The music is 100 beats a minute, so a bar is 2.4 seconds; every scene is a whole or half number of bars long, so the
cuts land on the beat. A film says which bar of the loop it starts on (`music.start_bar`); its end card gets the
ending chord.

A screen's scene points at things on it by their names in `regions.json` (`"focus": [[beat, "name", padding,
"what the lens shows"]]`): a ring goes round it, and a lens shows it up close, whole (`--regions` saves the box of all
an element draws, what sticks out of it too), with a little of the screen round it fading out, so nothing ends in a
hard cut. A few screens are taken for the videos alone (`wishlist-prices`, `downloads-files`), scrolled so what
they look at closely isn't cut off by the page's edge. `tests/test_promo.py` checks every name a film uses is there.

Only made-up data is shown: a data folder `scripts/screenshots.py` makes, never yours, with the products given. A
store's own pages are never shown: a step outside Hoard (a store's sign-in window) is a plain drawing of a window.
