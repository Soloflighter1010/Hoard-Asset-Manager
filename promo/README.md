# Hoard's videos

The promos ([#273](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/273)) and the help videos
([#274](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/274)) are made here, and so is their music
([#291](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/291)). Nothing in them is generated by a model:
the pictures are Hoard's own screens, taken by `scripts/screenshots.py`, and shapes drawn in HTML and SVG; the music
is notes written out in `music/loop.py` and synthesised there.

| | |
|---|---|
| `films/` | One file a video: its scenes, each a number of bars long, with its words in English, Japanese and Korean |
| `video/film.html` | Draws a film, one frame at a time |
| `build.py` | Takes a picture of every frame, checks it, and puts the video together with the music |
| `music/loop.py` | The music: a loop of 32 bars with no seam, and the chord a video ends on |
| `regions.json` | Things on Hoard's pages a film can point at, by name, found again in every language |

## Making them

You need Python with numpy, scipy and Pillow, Playwright's Chromium, and ffmpeg.

```
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark --lang=en --regions=promo/regions.json
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark --lang=ja --regions=promo/regions.json
python scripts/screenshots.py PRODUCTS_FOLDER build/shots --themes=dark --lang=ko --regions=promo/regions.json
python promo/music/loop.py
python promo/build.py promo-short help-booth-signed-out --lang=en,ja,ko --shape=landscape,portrait
```

`PRODUCTS_FOLDER` is the products the website's screenshots show, the ones listed on its
[credits page](https://hoard.furryup.link/credits.html) (`scripts/export_screenshot_products.py` makes such a folder
from a library). The videos land in `build/promo/out/`, named `hoard-<film>-<lang>-<shape>.mp4`.

`python promo/build.py FILM --preview=2,9.5,14` takes pictures of a few moments instead, to look at while writing a
film. Each frame is checked as it's drawn: a highlight or a picture that would run off the frame, or out of its window,
stops the build and says where.

The music is 100 beats a minute, so a bar is 2.4 seconds; every scene is a whole or half number of bars long, so the
cuts land on the beat. A film says which bar of the loop it starts on (`music.start_bar`); its end card gets the
ending chord.
