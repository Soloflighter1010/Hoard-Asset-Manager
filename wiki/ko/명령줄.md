Hoard 창에서 하는 모든 일은 명령으로도 할 수 있어요. 스크립트, 예약 작업, 데스크톱이 없는 컴퓨터(NAS 같은 것)를 위해서예요.

## 명령 실행하기

- **설치한 앱:** Hoard 폴더 `%LOCALAPPDATA%\Programs\Hoard`에 있는 `hoard-cli.exe`예요. `PATH`에 없으니 전체 경로를 쓰세요.

  ```
  "%LOCALAPPDATA%\Programs\Hoard\hoard-cli.exe" sync
  ```

- **Mac 앱:** `/Applications/Hoard.app/Contents/MacOS/hoard-cli <command>`.
- **Flatpak:** `flatpak run io.github.soloflighter1010.Hoard <command>`.
- **소스에서:** Windows에서는 `Hoard.bat <command>`, macOS와 Linux에서는 `./run.sh <command>`.

아래 예시는 `hoard-cli`라고 썼어요. 이 중에 맞는 것을 쓰세요. 명령 없이 실행하면 Hoard가 창으로 열려요(`--browser`면 웹 브라우저에서 열려요).

## 명령

| 명령 | 하는 일 |
|---|---|
| `login <store>` | 브라우저 창에서 스토어(`booth`, `gumroad`, `jinxxy`, `payhip`)에 로그인하거나, itch.io API 키를 추가해요(`itch`) |
| `logout <store>` | Hoard에서 스토어에서 로그아웃해요. `all`이면 모든 스토어에서 |
| `refresh [--store <store>]` | 스토어에서 가진 것을 읽어요(여러 개면 `--store`를 반복. 기본은 모두) |
| `import <file or folder>... [--store <store>] [--trust-shop <address>]` | 평소 쓰는 브라우저에서 저장한 라이브러리 페이지(`.mhtml`이나 `.html`)를 추가해요. 파일은 몇 개든, 그것들이 든 폴더도 돼요. 목록에 없는 Payhip 상점은 `--trust-shop`과 정확한 주소를 줄 때만 추가해요(여러 개면 반복). 가져오지 못한 페이지가 있으면 종료 코드 1로 끝나요 |
| `sync` | 새것이나 바뀐 것을 모두 다운로드해요. Payhip은 목록만 보여 주니 빼요(옵션은 아래) |
| `tags` | 다운로드한 것으로 `catalog.json`과 `tags.json`을 다시 만들어요 |
| `verify` | 데이터 파일이 Hoard 밖에서 바뀌었는지 확인한 다음 카탈로그 파일을 다시 만들어요. 무언가 바뀌었으면 종료 코드 1로 끝나요 |
| `self-test` | 이 Hoard에 필요한 것이 다 있는지 확인해요 |
| `migrate <folder>` | Hoard 1.x에서 라이브러리 목록과 다운로드 폴더를 가져와요 |
| `install-browser` | Hoard 전용 브라우저를 다운로드해요(Microsoft Edge가 없을 때만 필요해요) |
| `debug <store> [--raw]` | 문제 해결을 위해 스토어의 라이브러리 페이지와 Hoard가 거기서 읽은 것의 요약을 저장해요. 개인 정보는 빼요. `--raw`는 스크린숏과 함께 모두 남겨요 |
| `probe jinxxy [--raw]` | 문제 해결을 위해 Jinxxy 사이트가 불러오는 것을 기록해요(같은 방식으로 개인 정보를 빼요) |

`sync` 옵션:

- `--store <store>`: 스토어 하나만. `booth`, `gumroad`, `jinxxy`, `itch`(기본은 모두)
- `--dry-run`: 무엇을 다운로드할지 보여 주기만 하고 아무것도 다운로드하지 않아요
- `--only <text>`: 이름이나 제작자에 그 글자가 든 상품만
- `--headed`: Booth나 Jinxxy에서 다운로드할 때 브라우저를 보여 줘요

모든 명령은 `--config <file>`로 다른 설정 파일을 쓸 수 있어요(기본은 Hoard 앱 데이터 폴더의 `config.json`).

## 예시

아무것도 다운로드하지 않고 동기화가 무엇을 가져올지 보기:

```
hoard-cli sync --dry-run
```

Booth에서 한 제작자의 상품만 다운로드하기:

```
hoard-cli sync --store booth --only "Kitsu Studio"
```

폴더에 저장한 모든 페이지(모든 상점의 Payhip 라이브러리 페이지 같은 것) 가져오기:

```
hoard-cli import "D:\Saved pages\Payhip"
```

아무것도 변조되지 않았는지 확인하기(스크립트에서 쓸모 있어요. 변조가 있으면 종료 코드 1로 끝나요):

```
hoard-cli verify
```

## 일정에 맞춰 동기화하기

- **Windows:** **작업 스케줄러**에서 내 계정으로 `%LOCALAPPDATA%\Programs\Hoard\hoard-cli.exe`를 인수 `sync`로 실행하는 작업을 만드세요.
- **macOS와 Linux:** Mac 앱의 `hoard-cli`, `flatpak run io.github.soloflighter1010.Hoard sync`, 또는 Hoard 폴더에서 `./run.sh sync`를 실행하는 cron 작업이나 systemd 타이머를 쓰세요.

먼저 앱이나 `login`으로 스토어에 로그인하세요. `sync`는 Payhip을 열지 않아서(Hoard는 거기서 산 것을 목록으로만 보여 줘요), 컴퓨터 앞에 아무도 없어도 돼요. 같은 때에 Hoard가 스토어를 처리하는 중이면, 명령은 방해하지 않고 그렇다고 알려 줘요.

## Hoard를 서버로 실행하기

`--no-open`, `--port`, `--host`를 붙여 시작하면 Hoard는 **Ctrl+C**로 멈출 때까지 서버로 실행되고, 열 수 있는 주소를 보여 줘요. 그 주소에는 매번 새로운 접근 키가 들어 있어요. [다른 기기에서 쓰기](다른-기기에서-쓰기)를 보세요.
