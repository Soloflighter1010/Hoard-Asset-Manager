자주 쓰는 선택은 **설정**(오른쪽 위 **메뉴** 안. `settings:`로 검색할 수도 있어요)에 있어요. 잘 쓰지 않는 몇 가지는 `config.json`에만 있어요.

## 설정 페이지

설정은(5.1.3부터) 따로 된 페이지로, [프로젝트](프로젝트)처럼 위쪽 막대 아래 창 전체를 써요. 각 부분(**폴더**, **Hoard의 폴더**, **스토어**, **다운로드 중**, **알림**, **모양**, **로그인**, **업데이트**, **백업**, **문제 해결**, **Hoard 후원하기**, **감사의 말**)이 옆에 나와서, 고르면 그리로 가요. 좁은 창에서는 위에 나와요. **×**나 Esc로 닫혀요. 바꾼 것은 **바꾸는 즉시 저장돼요**. 체크 상자나 목록은 바로, 폴더나 Payhip 상점은 입력란을 떠날 때예요. 제목 줄에 **저장함**이라고 나와요.

- **다운로드 폴더:** 다운로드한 파일을 저장하는 곳이에요. 다른 곳을 고르지 않으면 문서 폴더 안의 `Hoard` 폴더예요. **찾아보기…** 버튼은 시스템의 폴더 선택 창을 열어요(Hoard 전용 창에서). 경로를 입력해도 돼요. **기본**으로 되돌려요. 바꿔도 이미 다운로드한 파일은 옮기지 않으니, 새 곳에 두고 싶다면 직접 옮기세요.
- **라이브러리 폴더:** 다운로드 폴더와, Hoard가 라이브러리의 일부로 읽는 다른 드라이브(외장 디스크 같은 것)의 폴더예요. 각각 들어 있는 다운로드 개수와 드라이브의 남은 공간(또는 드라이브가 연결되지 않았다는 것), 그리고 **열기**가 나와요. **폴더 추가…** 버튼으로 폴더를 골라 추가하거나(Hoard 창에서), 경로를 입력하고 **추가**를 고르세요. **삭제**는 Hoard가 그 폴더를 읽지 않게 할 뿐, 파일은 남아요. 폴더마다 다운로드에 탭이 생겨요. [다운로드](다운로드#다른-드라이브의-라이브러리-폴더)를 보세요.
- **Hoard의 폴더:** Hoard가 쓰는 모든 폴더와 각각의 쓰임과 위치로, 모두 **열기**가 있어요. 다운로드 폴더와 라이브러리 폴더, 편집용 사본(과 내용 보기로 꺼낸 것), Hoard 자체의 폴더(설정, 라이브러리 목록, 태그, 세트), 로그, 백업, 지원 보고서, 스토어 로그인(Hoard 전용 브라우저 프로필. 안의 내용은 절대 다른 사람에게 주지 마세요), 그리고 프로젝트의 것(Creator Companion의 폴더, 새 프로젝트를 만드는 곳, 프로젝트 백업)이에요. 아직 없는 것은 그렇게 알려 줘요. Hoard 자체의 폴더는 열 때 만들어져요. [Hoard가 저장하는 곳](Hoard가-저장하는-곳)을 보세요.
- **스토어:** Hoard가 보여 주고 읽는 스토어와 몇 가지 옵션이에요.
  - Booth: **선물 포함**과 **무료 다운로드 포함**.
  - Gumroad: **보관한 구매품 포함**.
  - itch.io: **게임 빌드(Windows, macOS, Linux, Android용 파일) 건너뛰기**(끄지 않으면 켜져 있어요): 제작자가 Windows, macOS, Linux, Android용 프로그램으로 표시한 파일은 다운로드하지 않아요. [스토어](스토어#itchio)를 보세요.
- **Payhip 상점:** Payhip에서 구매한 상점을 한 줄에 하나씩(`myshop.store`나 `payhip.com/ShopName` 같은 것). 상점의 저장한 페이지를 가져오면 자동으로 추가돼요. Hoard는 거기서 산 것을 목록으로 보여 주고, 파일은 Payhip에서 직접 다운로드해요. [스토어](스토어#payhip)를 보세요.
- **스토어의 태그:** **크리에이터가 상품에 붙인 태그 읽기**(5.2.0, 끄지 않는 한 켜져 있어요): Booth, Jinxxy, itch.io에서 스토어를 읽을 때마다 상품 몇 개의 공개 페이지를 읽어요. [태그](태그)를 보세요.
- **오프라인:** **상품 이미지를 저장해서 오프라인에서도 라이브러리 쓰기**.
- **상품을 다운로드하기 전에 저장할 파일 묻기**(5.2.0, 끄지 않으면 켜져 있어요): 아이템 상세 정보의 **다운로드**, **업데이트**, **더 다운로드...**는 먼저 **어떤 파일을 저장할까요?** 하고 물어요. [다운로드](다운로드#저장할-파일-고르기)를 보세요.
- **빼고 받을 파일**(5.2.0): 모든 스토어(또는 한 스토어)의 다운로드에서 뺄 파일. 파일 종류(**Unity 패키지**, **압축 파일**, PSD 같은 **레이어 이미지**, **이미지와 텍스처**, **Blender 파일**, **Substance Painter 프로젝트**, **3D 모델**, **소리**, **동영상**, **문서**)나, 이름에 정한 말(`quest, android` 같은 것)이 든 파일이에요. 동기화, 새것 다운로드, 정기 점검이 이걸 따라요. 새것 다운로드 목록이나, 저장할 파일을 물을 때 체크한 파일은 그래도 다운로드돼요. [다운로드](다운로드#저장할-파일-고르기)를 보세요.
- **라이브러리의 새것:** 새로고침 뒤 라이브러리에 나타난 것이 **새것** 배지를 다는 기간이에요. 하루, 3일, 일주일(다르게 고르지 않으면), 2주, 한 달, 또는 안 함. [라이브러리](라이브러리#찾기)를 보세요.
- **실패한 다운로드:** 파일 다운로드가 실패하면(연결이 끊기거나 서버가 바쁠 때) 잠깐 기다렸다가 다시 해요. 다르게 고르지 않으면 두 번이고, 한 번, 세 번, 또는 안 함도 고를 수 있어요. 스토어가 파일이 없다거나 내 것이 아니라고 하면 다시 하지 않아요.
- **이전 버전**(4.0): 업데이트가 파일을 바꿀 때 예전 사본을 몇 개 남길지예요. 다르게 고르지 않으면 마지막 하나이고, 없음, 또는 마지막 2, 3, 5개도 고를 수 있어요. [다운로드](다운로드#이전-버전)를 보세요.
- **정기 점검:** 6시간마다, 12시간마다, 하루에 한 번, 일주일에 한 번, 한 달에 한 번 중 하나를 고르지 않으면 **끔**(요청할 때만)이에요. Hoard가 열려 있는 동안 실행돼요. 스토어를 읽고(Payhip은 빼요), 다운로드를 점검하고, 업데이트를 확인한 다음, 찾은 것 중 무엇을 다운로드할지 물어봐요. 예전의 **자동 동기화**와 **다운로드 점검**을 대신하고, 켜 두었던 동기화의 간격은 그대로 이어져요. [다운로드](다운로드#다운로드하기)를 보세요. **다운로드할 것을 찾으면 시스템 알림으로 알려주기**(끄지 않으면 켜져 있어요, 3.1부터)는 Hoard가 백그라운드에서 열려 있는 동안 새 상품이나 업데이트를 찾으면 시스템 알림을 보여 줘요.
- **Apprise로 알림**(5.2.0): 고른 소식을 Apprise를 통해 Discord, Telegram, ntfy, 이메일 등 [여러 서비스](https://github.com/caronc/apprise/wiki)로 보내요. 서비스마다 주소를 한 줄에 하나씩 입력하거나, **주소 만들기**(5.2.0 beta 2)에서 서비스(Discord, Telegram, ntfy, 이메일, Pushover, Slack, Matrix, Gotify, 웹훅)를 고르고 서비스가 알려 준 내용을 채운 뒤 **칸에 넣기**를 고르세요. 그다음 **이 주소 보관하기**를 고르고, **테스트 보내기**로 도착하는지 확인하세요. 주소에는 각 서비스의 토큰이 들어 있어서, Hoard는 API 키처럼 보관하고([보안과 개인정보](보안과-개인정보)를 보세요) config.json에는 쓰지 않아요. 설정에는 보관한 개수만 나오고, **잊기**로 지울 수 있어요. 그다음 보낼 것에 체크하세요. 정기 점검이 찾은 새 상품과 업데이트, 위시리스트 상품이 싸졌을 때, 작업이 끝나거나 실패했을 때, 정기 점검이 끝났을 때, 그 밖의 소식(Hoard의 새 버전, 다운로드 점검이 바뀐 파일이나 없는 파일을 찾았을 때)이에요. 체크하지 않은 것은 보내지 않고, 보내는 내용은 개수뿐이며 상품 이름은 보내지 않아요.
- **모양**(3.2부터):
  - **언어**(3.3부터): **컴퓨터 설정 따르기**, **English**(영어), **日本語**(일본어), **한국어**. '컴퓨터 설정 따르기'는 시스템이나 브라우저가 요청하는 언어 중 이 가운데 첫 번째 것을 쓰고, 아무것도 요청하지 않으면 영어를 써요. 고른 언어로 페이지가 다시 열려요. 상품 이름, 제작자, 태그, 파일은 절대 번역하지 않아요. 작업 로그, Hoard for Unity, 웹사이트는 영어예요. 일본어와 한국어 번역은 AI의 도움을 받아 만들어서 어색한 표현이 있을 수 있어요. 이상한 곳이 있으면 [알려 주세요](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=translation.yml).
  - **컴퓨터 설정 따르기**, **라이트**, **다크**: Hoard가 컴퓨터의 라이트·다크 설정을 따르거나, 고른 쪽으로 남아요.
  - **테마**(각각 라이트와 다크 버전이 있어요): **Hoard**(동굴과 금), **드래곤파이어**, **얼음 동굴**, **지오드**, **이끼 낀 유적**, **신스웨이브**, **벚꽃**, **한밤과 종이**(OLED 화면용 완전한 검정과, 흰색), **고대비**, 그리고 계절 테마 두 가지: **으스스한 Hoard**와 **겨울 Hoard**(5.2.0, 눈과 밤하늘에 호랑가시나무의 빨강). 강조색이 스토어 색과 비슷한 테마에서는, 헷갈리지 않게 그 스토어의 색이 조금 바뀌어요. **스토어 색**(아래)은 어느 테마에서나 적용돼요.
  - **스타일**(5.0): 색과는 별개로, Hoard가 모든 것을 배치하는 방식이에요. **기본**은 지금까지의 Hoard 그대로이고, 타일 아래쪽에 스토어 색이 들어가요. **트레저**는 그림을 크게, 스토어 색 테두리와 스토어 이름을 붙여 보여 주고, 버튼과 탭이 둥글어져요. 상품 상세에서는 그림이 크고, 그 상품의 정보가 한 줄로 놓여요. **워크벤치**는 라이브러리, 다운로드, 세트를 촘촘한 목록(작은 그림, 이름과 제작자, 스토어, 다운로드했는지나 들어 있는 것, 추가한 날)으로 바꾸고, 컴퓨터의 글꼴로 보여 줘요. 모서리가 각지고, 막대와 패널, 표도 낮아져서 한눈에 더 많이 볼 수 있어요. 스타일은 고르는 대로 두 페이지에 바로 보이고, 다른 설정과 함께 저장되어서, Hoard를 다시 시작하거나 업데이트해도(백업에서도) 그대로예요. 어느 테마든, 라이트와 다크도, **접근성** 설정도 세 스타일 모두에서 쓸 수 있어요. Hoard for Unity와 공유 세트 페이지는 각자의 모양 그대로예요.
- **접근성:**
  - **글자 크기:** **보통**, **조금 크게**, **크게**, **가장 크게**. 페이지의 모든 것이 글자와 함께 커져요.
  - **글꼴:** **기본**, 또는 **OpenDyslexic(난독증용)**(4.1.0). 글자 아래쪽이 무겁고 모양이 서로 구별되는(b, d, p, q) 서체로, 난독증이 있는 많은 사람이 더 읽기 쉽다고 느껴요. 라틴 문자용이라서 일본어와 한국어는 Hoard 자체의 글꼴을 그대로 써요.
  - **글자, 낱말, 줄 사이를 넓게**(4.1.0): OpenDyslexic과 함께든 아니든 많은 사람에게 더 읽기 쉬워요.
  - **상품 카드에 테두리와 옅은 배경 넣기**(5.2.0): 상품 카드가 하나하나 페이지와 뚜렷이 구별돼요. 테두리는 흐린 글자만큼 또렷한 색이고, 카드가 보이는 곳(라이브러리, 다운로드, 세트, 위시리스트, 프로젝트) 어디서나, 어떤 스타일과 테마에서도 쓸 수 있어요.
  - **움직이는 이미지 멈추기:** 움직이는 상품 이미지(GIF 등)를 첫 프레임의 정지 이미지로 보여 줘요. 끄면 다시 움직여요.
  - **움직임 줄이기:** 미끄러지는 패널, 떠오르는 타일, 움직이는 진행 표시를 없애요. 컴퓨터 자체 설정이 움직임을 줄이라고 하면 Hoard도 그렇게 해요.
  - **페이지 뒤의 색 빛:** 창 아래에서 올라오는 스토어들의 색이에요. 끄면 단색 배경이 돼요. 빛이 보이는 곳에 쓰인 것(사이드바, 바닥글, 타일 이름)은 페이지 자체의 색 위에 있어서, 어느 테마에서든 빛 위에서도 빛이 없을 때만큼 또렷하게 읽혀요(5.2.0 beta 2).
  - **계절의 비밀**(5.2.0 beta 2): Spooky Hoard나 Winter Hoard를 쓰면, Hoard가 백그라운드에 있는 동안 페이지 가장자리에 먼지와 거미줄(Spooky)이나 눈과 얼음(Winter)이 천천히 쌓여요. 마우스를 이리저리 움직이면 걷히고, 탭을 바꾸면 한 번에 사라져요. 가장자리에만 쌓이고 클릭을 방해하지 않아요. **움직임 줄이기**를 켜면 꺼지고, 여기서 끌 수도 있어요.
  - **스토어 색:** **기본**, **구별하기 쉬운 색(색각 이상)**(흔한 색각 이상이 있어도 구별되고, 밝은 배경과 어두운 배경 모두에서 또렷하게 고른 색), 또는 **직접 고르기**(스토어마다(그리고 로컬) 내가 고르는 색). **기본**을 다시 고르면 돌아가요.

  이것들은 두 보기 모두에 바로 적용돼요.
- **업데이트:** **업데이트 자동 확인**(5.1부터는 끄지 않으면 켜져 있어요. 전부터 쓰던 Hoard는 내가 고른 그대로예요): Hoard가 시작할 때마다, 그리고 열려 있는 동안 하루에 한 번, 새 버전이 있는지 백그라운드에서 GitHub에 물어봐요. **지금 확인**은 바로 물어보고, **(버전)(으)로 업데이트**는 설치해요(`Hoard-Setup`으로 설치한 앱에서). [Hoard 설치](Hoard-설치#업데이트)를 보세요. 업데이트가 기다리는 동안(3.1.1부터) 위쪽의 Hoard 로고가 빛나요(움직임을 줄이지 않았다면 가끔 흔들려요). 고르면 바로 여기로 와요. **베타 업데이트 받기**(켜지 않으면 꺼져 있어요)는 테스터용이에요. 다음 버전의 베타도 업데이트로 치고, 완성 버전이 나오면 그것도 알려 줘요. 베타에는 문제가 있을 수 있어요. **Hoard의 새로운 기능**은 변경 기록을 버전별로, 실행 중인 버전에 표시해서 보여 줘요. 거기서 **베타 업데이트 포함**에 체크하면 베타의 변경 사항도 보여요.
- **스토어 로그인에 쓸 브라우저:** **자동**(Windows에서는 Microsoft Edge, 그 밖에서는 Hoard 전용 브라우저), **Microsoft Edge**, **Google Chrome**, **Hoard 전용 브라우저**. 바꾼 뒤에는 스토어에 다시 로그인해야 할 수도 있어요.

Hoard가 새로고침하거나 다운로드하는 동안에는 다운로드 폴더, 브라우저, 스토어, Payhip 상점을 바꿀 수 없어요(작업이 쓰는 중이라서). 그중 하나를 바꾸면 되돌려지니, 작업이 끝난 뒤 다시 바꾸세요. 다른 것은 바로 바뀌어요.

여기에는 이런 것도 있어요.

- **백업**(4.0): **백업 만들기**는 Hoard에서 설정한 것을 문서 폴더 안의 `Hoard backups`에 파일 하나로 저장해요. 설정(다운로드 폴더와 다른 라이브러리 폴더를 위치로), 태그, 세트, 보관과 삭제 선택, 다운로드 링크를 뺀 라이브러리 목록이에요. 숨긴 아이템과 그걸 숨기는 PIN과 복구 단어(시간이 오래 걸리는 해시로. 단어나 PIN 자체는 들어가지 않아요)는 숨긴 라이브러리의 잠금을 푼 동안에만 들어가요. 스토어 로그인, itch.io 키, Hoard가 기록을 봉인하는 키, 세트의 [짧은 링크](세트#짧은-링크)(되돌릴 때는 이 컴퓨터의 것을 남겨요), 다운로드한 것은 절대 들어가지 않아요. 새 컴퓨터에서는 다운로드 폴더를 직접 복사하고 스토어에 다시 로그인하세요. **백업에서 되돌리기...** 버튼은 파일에 무엇이 들었는지 물어보고, 먼저 지금 상태의 백업("before restoring" 표시)을 저장한 다음, 파일의 설정, 태그, 세트, 선택을 되돌려요. 모두 여기서 설정할 때처럼 확인해요. 이 컴퓨터에 없는 폴더는 그대로 두고, 드라이브 전체나 홈 폴더나 Hoard 자체 앱 데이터 폴더로 된 다운로드 폴더도 그대로 둬요. 라이브러리 목록은 아직 아무것도 없는 스토어만 채워요. 숨긴 아이템이 든 백업은 숨긴 라이브러리의 잠금을 풀어야 내 것을 대신해요. 잠긴 동안 만든 백업은 어디에도 숨긴 상품의 이름을 넣지 않고(4.2.0부터), 그걸 되돌려도 숨긴 상품의 태그, 세트, 선택은 그대로예요.
- **Hoard 다시 설정:** 설정 도우미를 단계별로. [시작하기](시작하기)를 보세요.
- **둘러보기:** Hoard가 할 수 있는 일을 내 라이브러리로 보여 줘요(4.1.0). [시작하기](시작하기#둘러보기)를 보세요.
- **창을 닫으면 Hoard가 작업 표시줄(Mac에서는 Dock)로 최소화되고 계속 작동해요**(Hoard 전용 창에서. 끄지 않으면 켜져 있어요): 닫기 버튼이 창을 작업 표시줄(Mac에서는 Dock)로 최소화하고, 다운로드, 동기화, 정기 점검은 계속돼요. 거기서 클릭하거나 Hoard를 다시 열면 창이 돌아와요. 끄면 닫기 버튼으로 종료해요(무언가 실행 중이면 먼저 물어봐요). Mac에서 **Command-Q**는 언제나 **Hoard 종료**처럼 종료해요.
- **Hoard 종료:** Hoard를 멈춰요. 무언가 실행 중(또는 차례를 기다리는 중)이면 창을 닫을 때처럼 먼저 물어봐요. [작업 중에 Hoard 닫기](다운로드#작업-중에-hoard-닫기)를 보세요.
- **Hoard 후원하기**(5.2.0): **Ko-fi로 팁 보내기**를 누르면 Hoard의 Ko-fi 페이지가 브라우저에서 열려요. Hoard가 도움이 된다면 팁을 보낼 수 있어요. Hoard 자체는 아무것도 보내지 않아요.
- **감사의 말**(5.2.0): Hoard가 쓰거나 함께 담는 모든 것(조작하는 브라우저, 글꼴, Python 패키지, 앱을 만드는 도구)을 각각의 라이선스와 함께 보여 줘요. Hoard에 사본이 있는 것은 고르면 라이선스를 읽을 수 있고, 나머지는 링크에 있어요. 웹사이트의 [감사의 말](https://hoard.furryup.link/acknowledgements.html) 페이지에도 같은 목록이 있어요.

## config.json에만 있는 설정

`config.json`은 Hoard의 앱 데이터 폴더에 있어요. Windows에서는 `%LOCALAPPDATA%\Hoard`, macOS에서는 `~/Library/Application Support/Hoard`, Linux에서는 `~/.local/share/Hoard`예요. 편집하기 전에 Hoard를 종료하고, 올바른 JSON으로 유지하세요.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `allow_unprotected_signins` | `false` | 키링이 없는 Linux에서만: 로그인을 폴더 권한만으로 보호해서 보관해요 |
| `automated_sign_in` | `false` | 브라우저 자체의 창 대신 2.11 이전처럼 Hoard가 조작하는 창에서 스토어에 로그인해요. Google, Discord, X는 거기서 로그인을 거부하니, 브라우저 자체의 창에 문제가 있을 때만 쓰세요 |
| `profile_dir` with `advanced_signin_location` | `""`, `false` | 로그인을 Hoard의 비공개 폴더가 아닌 곳에 보관해요. `advanced_signin_location`이 `true`일 때만 쓰고, 네트워크 공유에는 절대 두지 않아요. 그때 얼마나 보호되는지는 그 드라이브에 달려 있어요 |
| `routine_hours` | `null` | Hoard가 열려 있는 동안 정기 점검 사이의 시간: `0`(끔), `6`, `12`, `24`, `168`, `720`(설정의 **정기 점검**). 고르기 전에는 `null`이고, 그다음에는 `auto_sync_hours`를 켰다면 그 값, 아니면 `0`(끔) |
| `auto_sync_hours`, `integrity_check_days` | | 3.0 이전: 자동 동기화 간격과 다운로드 점검 간격. `auto_sync_hours`는 정기 점검의 첫 간격을 정할 때만 읽어요 |
| `display.text_size` | `100` | 글자 크기(퍼센트): `100`, `115`, `130`, `150`(설정의 **접근성**) |
| `download_skip` | `[]` | 다운로드할 때 항상 건너뛰는 상품(태그 키로)(**새것 다운로드**가 보여 주는 목록의 **항상 건너뛰기**. [다운로드](다운로드)를 보세요) |
| `display.font` | `"standard"` | `"standard"` 또는 `"dyslexic"`(OpenDyslexic. 설정 **접근성**의 **글꼴**) |
| `display.spacing` | `false` | 글자, 낱말, 줄 사이를 넓게(설정의 **접근성**) |
| `display.card_outlines` | `false` | 상품 카드에 테두리와 옅은 배경 넣기(설정의 **접근성**) |
| `display.glow` | `true` | 페이지 뒤의 색 빛(설정의 **접근성**) |
| `display.seasonal` | `true` | 계절의 비밀, Spooky Hoard와 Winter Hoard에서(설정의 **접근성**) |
| `display.colours` | `"standard"` | 스토어 색: `"standard"`, `"colourblind"`, `"custom"`(설정의 **스토어 색**) |
| `display.theme` | `"hoard"` | 테마: `hoard`, `dragonfire`, `frost`, `geode`, `moss`, `synthwave`, `sakura`, `midnight`, `contrast`, `spooky`, `winter`(설정의 **모양**) |
| `display.mode` | `"system"` | `"system"`(컴퓨터 설정 따르기), `"light"`, `"dark"`(설정의 **모양**) |
| `display.style` | `"standard"` | 스타일: `"standard"`, `"treasure"`, `"workbench"`(설정의 **모양**) |
| `display.language` | `"system"` | `"system"`(컴퓨터 설정 따르기), `"en"`, `"ja"`, `"ko"`(설정의 **모양**) |
| `display.custom_colours` | `{}` | 직접 고른 스토어 색. 스토어(`booth`, `gumroad`, `jinxxy`, `payhip`, `itch`, `local`)마다 `#rrggbb`로. `colours`가 `"custom"`일 때 써요 |
| `check_for_updates` | `true` | Hoard가 시작할 때마다, 그리고 열려 있는 동안 하루에 한 번, 새 버전이 있는지 백그라운드에서 GitHub에 물어봐요(설정의 **업데이트** 체크 상자) |
| `beta_updates` | `false` | 베타(`v<version>-beta.<n>` 태그의 사전 릴리스)도 업데이트로 쳐요(설정의 **베타 업데이트 받기**) |
| `close_to_taskbar` | `true` | Hoard 창을 닫으면 작업 표시줄로 최소화되고 Hoard는 계속 작동해요(설정의 **창을 닫으면 Hoard가 작업 표시줄(Mac에서는 Dock)로 최소화되고 계속 작동해요**) |
| `local_copy` | `true` | **내 것 추가**가 Hoard로 복사하기(`true`)와 지금 있는 곳에서 목록에 올리기(`false`) 중 무엇을 먼저 보여 줄지. 지난번 선택으로 정해져요 |
| `edits_root` | `""` | **편집용 사본 만들기**가 사본을 두는 곳. 비어 있으면 다운로드 폴더 옆의 **Hoard Edits**. 다운로드 폴더 안은 절대 안 돼요. [다운로드한 것 바꾸기](다운로드#다운로드한-것-바꾸기편집용-사본-만들기)를 보세요 |
| `request_delay` | `1.0` | 스토어 페이지를 불러오는 사이의 초 |
| `new_days` | `7` | 라이브러리의 새것에 **새것** 표시를 다는 날 수: `0`(안 함), `1`, `3`, `7`, `14`, `30`(설정의 **라이브러리의 새것**) |
| `keep_previous` | `1` | 업데이트가 바꾸는 파일마다 남기는 이전 버전 수: 설정에서는 `0`, `1`, `2`, `3`, `5`(**이전 버전**), 여기서는 `10`까지 |
| `download_retries` | `2` | 실패한 파일 다운로드를 몇 번 더 할지: 설정에서는 `0`부터 `3`(**실패한 다운로드**), 여기서는 `5`까지 |
| `payhip.bot_check_wait` | `180` | Payhip의 봇 확인을 내가 마치기를 기다리는 초 |
| `jinxxy.item_link_pattern` | | Jinxxy 인벤토리 페이지에서 어느 링크가 내 아이템인지 |
| `tags.min_count`, `tags.max_share` | `3`, `0.4` | 낱말이 추천 태그가 되는 조건: 적어도 이만큼의 이름에 있고, 이름의 이 비율보다 많이 있지 않을 것 |
| `tags.blocklist` | `[]` | 추천하지 않을 낱말(태그 패널의 **숨기기**도 같은 일을 해요) |

명령줄의 `--config <file>`은 다른 설정 파일을 써요. [명령줄](명령줄)을 보세요.
