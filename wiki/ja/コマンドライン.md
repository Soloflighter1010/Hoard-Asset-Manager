Hoardのウィンドウでできることは、すべてコマンドとしても使えます。スクリプト、スケジュールしたタスク、デスクトップのないコンピューター(NASなど)のためです。

## コマンドを実行する

- **インストールしたアプリ:** Hoardのフォルダー `%LOCALAPPDATA%\Programs\Hoard` にある `hoard-cli.exe` です。`PATH` には入っていないので、フルパスで指定します。

  ```
  "%LOCALAPPDATA%\Programs\Hoard\hoard-cli.exe" sync
  ```

- **Mac版アプリ:** `/Applications/Hoard.app/Contents/MacOS/hoard-cli <command>`。
- **Flatpak:** `flatpak run io.github.soloflighter1010.Hoard <command>`。
- **ソースから:** Windowsでは `Hoard.bat <command>`、macOSとLinuxでは `./run.sh <command>`。

下の例では `hoard-cli` と書いています。この中から合うものを使ってください。コマンドなしで実行すると、Hoardがウィンドウで開きます(`--browser` ではWebブラウザーで開きます)。

## コマンド

| コマンド | すること |
|---|---|
| `login <store>` | ブラウザーのウィンドウでストア(`booth`、`gumroad`、`jinxxy`、`payhip`)にサインインする、またはitch.ioのAPIキーを追加する(`itch`) |
| `logout <store>` | Hoardでストアからサインアウトする。`all` ですべてのストアから |
| `refresh [--store <store>]` | ストアから持っているものを読み込む(複数なら `--store` をくり返す。既定はすべて) |
| `import <file or folder>... [--store <store>] [--trust-shop <address>]` | ふだんのブラウザーで保存したライブラリページ(`.mhtml` または `.html`)を追加する。ファイルはいくつでも、それらが入ったフォルダーも指定できる。一覧にないPayhipのショップは、`--trust-shop` と正確なアドレスを指定したときだけ追加する(複数ならくり返す)。取り込めなかったページがあれば終了コード1で終わる |
| `sync` | 新しいもの、変わったものをすべてダウンロードする。Payhipは一覧表示のみなので除く(オプションは下) |
| `tags` | ダウンロードしたものから `catalog.json` と `tags.json` を作り直す |
| `verify` | データファイルがHoardの外で変更されていないか確かめてから、カタログのファイルを作り直す。何か変更されていれば終了コード1で終わる |
| `self-test` | このHoardに必要なものがすべてそろっているか確かめる |
| `migrate <folder>` | Hoard 1.xからライブラリの一覧とダウンロードフォルダーを引き継ぐ |
| `install-browser` | Hoard専用のブラウザーをダウンロードする(Microsoft Edgeがない場合だけ必要) |
| `debug <store> [--raw]` | トラブル解決のために、ストアのライブラリページと、Hoardがそこから読んだもののまとめを保存する。個人情報は取り除く。`--raw` ではすべてをスクリーンショットつきで残す |
| `probe jinxxy [--raw]` | トラブル解決のために、Jinxxyのサイトが読み込むものを記録する(同じように個人情報を取り除く) |

`sync` のオプション:

- `--store <store>`: 1つのストアだけ。`booth`、`gumroad`、`jinxxy`、`itch`(既定はすべて)
- `--dry-run`: 何をダウンロードするかを一覧にするだけで、何もダウンロードしない
- `--only <text>`: 名前かクリエイターにその文字が入った商品だけ
- `--headed`: BoothやJinxxyからダウンロードするとき、ブラウザーを表示する

どのコマンドでも `--config <file>` で別の設定ファイルを使えます(既定はHoardのアプリデータフォルダーの `config.json`)。

## 例

何もダウンロードせずに、同期で何を取得するかを見る:

```
hoard-cli sync --dry-run
```

Boothから、1人のクリエイターの商品だけをダウンロードする:

```
hoard-cli sync --store booth --only "Kitsu Studio"
```

フォルダーに保存したすべてのページ(すべてのショップのPayhipのライブラリページなど)を取り込む:

```
hoard-cli import "D:\Saved pages\Payhip"
```

何も改ざんされていないか確かめる(スクリプトで便利です。改ざんがあれば終了コード1で終わります):

```
hoard-cli verify
```

## スケジュールで同期する

- **Windows:** **タスク スケジューラ** で、自分のアカウントとして、`%LOCALAPPDATA%\Programs\Hoard\hoard-cli.exe` を引数 `sync` で実行するタスクを作ります。
- **macOSとLinux:** Mac版アプリの `hoard-cli`、`flatpak run io.github.soloflighter1010.Hoard sync`、またはHoardのフォルダーで `./run.sh sync` を実行するcronジョブかsystemdのタイマーを使います。

先に、アプリか `login` でストアにサインインしておいてください。`sync` はPayhipを開かない(Hoardはそこで買ったものを一覧にするだけ)ので、コンピューターの前にだれもいなくても動きます。同じときにHoardがストアの処理中なら、コマンドは邪魔をせず、そう伝えます。

## Hoardをサーバーとして動かす

`--no-open`、`--port`、`--host` をつけて起動すると、Hoardは **Ctrl+C** で止めるまでサーバーとして動き、開くためのアドレスを表示します。そのアドレスには毎回新しいアクセスキーが入っています。[ほかのデバイスで使う](ほかのデバイスで使う)をご覧ください。
