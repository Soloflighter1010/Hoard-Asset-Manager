ふだん使う選択は **設定**(右上の **メニュー** の中。`settings:` で検索もできます)にあります。あまり使わないものは、`config.json` にしかありません。

## 設定ページ

設定は(5.1.3から)それ専用のページで、[プロジェクト](プロジェクト)と同じく、上のバーの下のウィンドウ全体を使います。各部分(**フォルダー**、**Hoardのフォルダー**、**ストア**、**ダウンロード中**、**見た目**、**サインイン**、**アップデート**、**バックアップ**、**トラブルシューティング**)が横に並び、選ぶとそこへ移動します。狭いウィンドウでは上に並びます。**×** かEscで閉じます。変更は **変えたその場で保存されます**。チェックボックスや一覧はすぐに、フォルダーやPayhipのショップは入力欄を離れたときです。タイトルバーに **保存しました** と表示されます。

- **ダウンロードフォルダー:** ダウンロードしたファイルの保存先です。ほかを選ばなければ、ドキュメントの中の `Hoard` フォルダーです。**参照…** でシステムのフォルダー選択が開きます(Hoard専用のウィンドウで)。パスを入力することもできます。**既定** で元に戻ります。変えても、すでにダウンロードしたファイルは移動しないので、新しい場所に置きたい場合は自分で移動してください。
- **ライブラリフォルダー:** ダウンロードフォルダーと、Hoardがライブラリの一部として読む、ほかのドライブ(外付けディスクなど)のフォルダーです。それぞれ、入っているダウンロードの数と、ドライブの空き容量(またはドライブがつながっていないこと)、それに **開く** が表示されます。**フォルダーを追加…** でフォルダーを選んで追加するか(Hoardのウィンドウで)、パスを入力して **追加** を選びます。**削除** は、Hoardがそのフォルダーを読まなくなるだけで、ファイルは残ります。フォルダーごとに、ダウンロードにタブができます。[ダウンロード](ダウンロード#ほかのドライブのライブラリフォルダー)をご覧ください。
- **Hoardのフォルダー:** Hoardが使うすべてのフォルダーと、それぞれの用途と場所で、どれにも **開く** があります。ダウンロードフォルダーとライブラリフォルダー、編集用コピー(と「中身を見る」で取り出したもの)、Hoard自身のフォルダー(設定、ライブラリの一覧、タグ、セット)、ログ、バックアップ、サポートレポート、ストアのサインイン(Hoard専用のブラウザープロファイル。中身は決して人に渡さないでください)、そしてプロジェクトのもの(Creator Companionのフォルダー、新しいプロジェクトを作る場所、プロジェクトのバックアップ)です。まだないものはそう表示されます。Hoard自身のフォルダーは、開くときに作られます。[Hoardの保存場所](Hoardの保存場所)をご覧ください。
- **ストア:** Hoardが表示して読み込むストアと、いくつかのオプションです。
  - Booth: **ギフトを含める** と **無料ダウンロードを含める**。
  - Gumroad: **アーカイブした購入品を含める**。
  - itch.io: **ゲームのビルド(Windows、macOS、Linux、Android用のファイル)をスキップ**(オフにしない限りオン): クリエイターがWindows、macOS、Linux、Android用のプログラムとして指定したファイルはダウンロードしません。[ストア](ストア#itchio)をご覧ください。
- **Payhipのショップ:** Payhipで購入したショップを、1行に1つずつ(`myshop.store` や `payhip.com/ShopName` など)。ショップの保存したページを取り込むと、自動で追加されます。Hoardはそこで買ったものを一覧にし、ファイルはPayhipから自分でダウンロードします。[ストア](ストア#payhip)をご覧ください。
- **ストアのタグ:** **クリエイターが商品に付けたタグを読み込む**(5.2.0。オフにしない限りオン): Booth、Jinxxy、itch.ioで、ストアを読み込むたびにいくつかの商品の公開ページを読みます。[タグ](タグ)をご覧ください。
- **オフライン:** **商品の画像を保存して、オフラインでもライブラリを使えるようにする**。
- **除外するファイル**(5.2.0): すべてのストア(または1つのストア)のダウンロードから除外するファイル。ファイルの種類(**Unityパッケージ**、**圧縮ファイル**、PSDなどの **レイヤー画像**、**画像とテクスチャ**、**Blenderファイル**、**3Dモデル**、**音声**、**動画**、**文書**)か、名前に指定した言葉(`quest, android` など)を含むファイルです。同期、新しいものをダウンロード、定期チェックはこれに従います。新しいものをダウンロードの一覧でチェックしたファイルは、それでもダウンロードされます。1つの商品のファイルはその一覧で選びます。[ダウンロード](ダウンロード)をご覧ください。
- **ライブラリの新着:** 更新のあとにライブラリに現れたものが **新着** バッジをつけている期間です。1日、3日、1週間(ほかを選ばない限り)、2週間、1か月、またはなし。[ライブラリ](ライブラリ#探す)をご覧ください。
- **失敗したダウンロード:** ファイルのダウンロードが失敗したとき(接続が切れた、サーバーが混んでいた)、少し待ってからもう一度試します。ほかを選ばない限り2回で、1回、3回、または試さないも選べます。ストアがファイルはない、またはあなたのものではないと言った場合は、もう一度試しません。
- **以前のバージョン**(4.0): アップデートでファイルが置き換わるとき、古いコピーをいくつ残すかです。ほかを選ばない限り最新の1つで、なし、または最新の2、3、5個も選べます。[ダウンロード](ダウンロード#以前のバージョン)をご覧ください。
- **定期チェック:** 6時間ごと、12時間ごと、1日1回、週1回、月1回のどれかを選ばない限り **オフ**(頼んだときだけ)です。Hoardを開いている間に動きます。ストアを読み込み(Payhipは除く)、ダウンロードをチェックし、アップデートを確認してから、見つかったもののうちどれをダウンロードするかを聞きます。以前の **自動で同期** と **ダウンロードをチェック** の代わりになるもので、オンにしていた同期の間隔は引き継がれます。[ダウンロード](ダウンロード#ダウンロードする)をご覧ください。**ダウンロードするものが見つかったら、システムの通知で知らせる**(オフにしない限りオン、3.1から)は、Hoardがバックグラウンドで開いている間に新しい商品やアップデートが見つかると、システムの通知を出します。
- **外観**(3.2から):
  - **言語**(3.3から): **コンピューターに合わせる**、**English**(英語)、**日本語**、**한국어**(韓国語)。「コンピューターに合わせる」は、システムやブラウザーが求める言語のうち、この中で最初のものを使い、どれも求められていなければ英語を使います。選んだ言語でページが読み込み直されます。商品名、クリエイター、タグ、ファイルが翻訳されることはありません。タスクのログ、Hoard for Unity、Webサイトは英語です。日本語と韓国語の訳はAIの助けを借りて作ったので、不自然な表現があるかもしれません。おかしなところがあれば[教えてください](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=translation.yml)。
  - **コンピューターに合わせる**、**ライト**、**ダーク**: Hoardがコンピューターのライト・ダークの設定に合わせるか、選んだほうのままにします。
  - **テーマ**(それぞれライト版とダーク版があります): **Hoard**(洞窟と金)、**ドラゴンファイア**、**氷の洞窟**、**ジオード**、**苔むした遺跡**、**シンセウェーブ**、**桜**、**真夜中と紙**(OLED画面向けの真っ黒と、白)、**ハイコントラスト**、**ハロウィンのHoard**。アクセントの色がストアの色に近いテーマでは、取り違えないように、そのストアの色が少しずれます。**ストアの色**(下)は、どのテーマでも使われます。
  - **スタイル**(5.0):色とは別に、Hoardの画面の並べ方です。**標準** はこれまでどおりのHoardで、タイルの下にストアの色の帯が付きます。**トレジャー** は画像を大きく、ストアの色の枠とストア名を付けて表示し、ボタンとタブが丸くなります。商品の詳細では画像が大きく、その商品の情報が一列に並びます。**ワークベンチ** はライブラリ、ダウンロード、セットを詰めたリスト(小さな画像、名前と作者、ストア、ダウンロード済みかどうかや中身、追加日)にして、コンピューターのフォントで表示します。角は四角く、バー、パネル、表も低くなり、一度に多くを見渡せます。スタイルは選ぶとすぐに両方のページに反映され、ほかの設定と一緒に保存されるので、Hoardを起動し直しても、アップデートしても(バックアップでも)そのままです。どのテーマも、ライトとダークも、**アクセシビリティ** の設定も、3つのスタイルすべてで使えます。Hoard for Unityと共有セットのページは、それぞれの見た目のままです。
- **アクセシビリティ:**
  - **文字の大きさ:** **標準**、**やや大きい**、**大きい**、**最大**。ページのすべてが文字と一緒に大きくなります。
  - **フォント:** **標準**、または **OpenDyslexic(ディスレクシア向け)**(4.1.0)。文字の下側が重く、形が区別しやすい(b、d、p、q)書体で、ディスレクシアのある多くの人にとって読みやすいものです。ラテン文字用なので、日本語と韓国語はHoard自身のフォントのままです。
  - **文字・単語・行の間隔を広げる**(4.1.0): OpenDyslexicと一緒でもそうでなくても、多くの人にとって読みやすくなります。
  - **商品のカードに枠線と薄い背景をつける**(5.2.0): 商品のカードがそれぞれページから区別しやすくなります。枠線は控えめな文字と同じくらいはっきりした色で、カードが出るところ(ライブラリ、ダウンロード、セット、ほしい物リスト、プロジェクト)すべてで、どのスタイルとテーマでも使えます。
  - **アニメーション画像を止める:** アニメーションする商品の画像(GIFなど)を、最初のフレームの静止画で表示します。オフにすると、また動きます。
  - **動きを減らす:** パネルのスライド、タイルが浮き上がる動き、進み具合のアニメーションをなくします。コンピューター自体の設定で動きを減らすように求められている場合も、Hoardはこうします。
  - **ページの背景の色の光:** ウィンドウの下から立ちのぼるストアの色です。オフにすると、無地の背景になります。
  - **ストアの色:** **標準**、**見分けやすい色(色覚の多様性)**(よくある色覚の違いがあっても区別でき、明るい背景でも暗い背景でもはっきりするように選んだ色)、または **自分で選ぶ**(ストアごと(とローカル)に自分で選ぶ色)。**標準** をもう一度選ぶと戻ります。

  これらは両方の表示にすぐ反映されます。
- **アップデート:** **アップデートを自動で確認**(5.1からはオフにしない限りオン。前から使っているHoardは、あなたの選んだままです): Hoardを起動するたびと、開いている間は1日1回、新しいバージョンがあるかバックグラウンドでGitHubに問い合わせます。**今すぐ確認** ですぐに問い合わせ、**(バージョン)にアップデート** でインストールします(`Hoard-Setup` でインストールしたアプリの場合)。[Hoardのインストール](Hoardのインストール#アップデート)をご覧ください。アップデートが待っている間(3.1.1から)、上のHoardのロゴが光ります(動きを減らしていなければ、ときどき揺れます)。選ぶとここに直接来られます。**ベータ版のアップデートを受け取る**(オンにしない限りオフ)はテスター向けです。次のバージョンのベータ版もアップデートとして扱い、完成版が出たときにはそれも案内します。ベータ版には問題があるかもしれません。**Hoardの新機能** は、変更履歴をバージョンごとに、実行中のバージョンに印をつけて表示します。そこで **ベータ版のアップデートも含める** にチェックを入れると、ベータ版の変更も表示されます。
- **ストアのサインインに使うブラウザー:** **自動**(WindowsではMicrosoft Edge、それ以外ではHoard専用のブラウザー)、**Microsoft Edge**、**Google Chrome**、**Hoard専用のブラウザー**。変えたあとは、ストアにもう一度サインインする必要があるかもしれません。

Hoardが更新やダウンロードをしている間は、ダウンロードフォルダー、ブラウザー、ストア、Payhipのショップは変えられません(ジョブが使っているため)。それらを変えると元に戻されるので、ジョブが終わってからもう一度変えてください。ほかのものはすぐに変わります。

ほかにもここにあるもの:

- **バックアップ**(4.0): **バックアップを作る** で、Hoardで設定したものを、ドキュメントの中の `Hoard backups` に1つのファイルとして保存します。設定(ダウンロードフォルダーとほかのライブラリフォルダーを場所として)、タグ、セット、アーカイブと削除の選択、ダウンロードリンクを除いたライブラリの一覧です。非表示のアイテムと、それを隠すPINと復元ワード(時間のかかるハッシュとして。ワードやPINそのものは入りません)は、非表示のライブラリのロックを解除している間だけ入ります。ストアのサインイン、itch.ioのキー、Hoardが記録の封印に使うキー、セットの[短縮リンク](セット#短縮リンク)(元に戻すときは、このコンピューターのものを残します)、ダウンロードしたものは決して入りません。新しいコンピューターでは、ダウンロードフォルダーを自分でコピーして、ストアにもう一度サインインしてください。**バックアップから戻す...** は、ファイルに何が入っているかを聞き、先に今の状態のバックアップ(「before restoring」の印つき)を保存してから、ファイルの設定、タグ、セット、選択を戻します。どれも、ここで設定したときと同じように確かめます。このコンピューターにないフォルダーはそのままにし、ドライブ全体、ホームフォルダー、Hoard自身のアプリデータフォルダーになっているダウンロードフォルダーもそのままにします。ライブラリの一覧は、まだ何も一覧にないストアだけを埋めます。非表示のアイテムが入ったバックアップは、非表示のライブラリのロックを解除してはじめて、あなたのものと置き換わります。ロック中に作ったバックアップは、どこにも非表示の商品の名前を入れず(4.2.0から)、それを戻しても、非表示の商品のタグ、セット、選択はそのままです。
- **Hoardをもう一度セットアップ:** セットアップアシスタントを、1ステップずつ。[はじめに](はじめに)をご覧ください。
- **ツアーを見る:** Hoardでできることを、あなた自身のライブラリで紹介します(4.1.0)。[はじめに](はじめに#ツアー)をご覧ください。
- **ウィンドウを閉じるとHoardはタスクバー(MacではDock)に最小化され、動き続けます**(Hoard専用のウィンドウで。オフにしない限りオン): 閉じるボタンでウィンドウをタスクバー(MacではDock)に最小化し、ダウンロード、同期、定期チェックは続きます。そこでクリックするか、Hoardをもう一度開くと、ウィンドウが戻ります。オフにすると、閉じるボタンで終了します(何かが実行中なら先に確認します)。Macでは、**Command-Q** はいつも **Hoardを終了** と同じく終了します。
- **Hoardを終了:** Hoardを止めます。何かが実行中(または順番待ち)なら、ウィンドウを閉じるときと同じく先に確認します。[作業中にHoardを閉じる](ダウンロード#作業中にhoardを閉じる)をご覧ください。

## config.jsonだけにある設定

`config.json` はHoardのアプリデータフォルダーにあります。Windowsでは `%LOCALAPPDATA%\Hoard`、macOSでは `~/Library/Application Support/Hoard`、Linuxでは `~/.local/share/Hoard` です。編集する前にHoardを終了し、正しいJSONのままにしてください。

| 設定 | 既定値 | 意味 |
|---|---|---|
| `allow_unprotected_signins` | `false` | キーリングのないLinuxのみ: サインインを、フォルダーのアクセス権だけで守って保存する |
| `automated_sign_in` | `false` | ブラウザー自体のウィンドウではなく、2.11より前と同じHoardが操作するウィンドウでストアにサインインする。Google、Discord、Xはそこでのサインインを拒否するので、ブラウザー自体のウィンドウで問題があるときだけ使う |
| `profile_dir` with `advanced_signin_location` | `""`, `false` | サインインをHoardの非公開フォルダー以外に保存する。`advanced_signin_location` が `true` のときだけ使い、ネットワーク共有には決して保存しない。そのときの守られ方はそのドライブ次第 |
| `routine_hours` | `null` | Hoardを開いている間の定期チェックの間隔(時間): `0`(オフ)、`6`、`12`、`24`、`168`、`720`(設定の **定期チェック**)。選ぶまでは `null` で、そのあとは、`auto_sync_hours` をオンにしていればその値、そうでなければ `0`(オフ) |
| `auto_sync_hours`, `integrity_check_days` | | 3.0より前: 自動で同期する間隔と、ダウンロードをチェックする間隔。`auto_sync_hours` は、定期チェックの最初の間隔を決めるためだけに読む |
| `display.text_size` | `100` | 文字の大きさ(パーセント): `100`、`115`、`130`、`150`(設定の **アクセシビリティ**) |
| `download_skip` | `[]` | ダウンロードで常にスキップする商品(タグのキーで)(**新しいものをダウンロード** が表示する一覧の **常にスキップ**。[ダウンロード](ダウンロード)をご覧ください) |
| `display.font` | `"standard"` | `"standard"` または `"dyslexic"`(OpenDyslexic。設定の **アクセシビリティ** の **フォント**) |
| `display.spacing` | `false` | 文字・単語・行の間隔を広げる(設定の **アクセシビリティ**) |
| `display.card_outlines` | `false` | 商品のカードに枠線と薄い背景をつける(設定の **アクセシビリティ**) |
| `display.glow` | `true` | ページの背景の色の光(設定の **アクセシビリティ**) |
| `display.colours` | `"standard"` | ストアの色: `"standard"`、`"colourblind"`、`"custom"`(設定の **ストアの色**) |
| `display.theme` | `"hoard"` | テーマ: `hoard`、`dragonfire`、`frost`、`geode`、`moss`、`synthwave`、`sakura`、`midnight`、`contrast`、`spooky`(設定の **外観**) |
| `display.mode` | `"system"` | `"system"`(コンピューターに合わせる)、`"light"`、`"dark"`(設定の **外観**) |
| `display.style` | `"standard"` | スタイル: `"standard"`、`"treasure"`、`"workbench"`(設定の **外観**) |
| `display.language` | `"system"` | `"system"`(コンピューターに合わせる)、`"en"`、`"ja"`、`"ko"`(設定の **外観**) |
| `display.custom_colours` | `{}` | 自分で選んだストアの色。ストア(`booth`、`gumroad`、`jinxxy`、`payhip`、`itch`、`local`)ごとに `#rrggbb` で。`colours` が `"custom"` のときに使う |
| `check_for_updates` | `true` | Hoardを起動するたびと、開いている間は1日1回、新しいバージョンがあるかバックグラウンドでGitHubに問い合わせる(設定の **アップデート** のチェックボックス) |
| `beta_updates` | `false` | ベータ版(`v<version>-beta.<n>` というタグのプレリリース)もアップデートとして扱う(設定の **ベータ版のアップデートを受け取る**) |
| `close_to_taskbar` | `true` | Hoardのウィンドウを閉じるとタスクバーに最小化され、Hoardは動き続ける(設定の **ウィンドウを閉じるとHoardはタスクバー(MacではDock)に最小化され、動き続けます**) |
| `local_copy` | `true` | **自分のものを追加** で、Hoardにコピーする(`true`)か、今の場所のまま一覧にする(`false`)か、どちらを先に出すか。前回の選択で決まる |
| `edits_root` | `""` | **編集用のコピーを作る** がコピーを置く場所。空なら、ダウンロードフォルダーの横の **Hoard Edits**。ダウンロードフォルダーの中には決してしない。[ダウンロードしたものを変える](ダウンロード#ダウンロードしたものを変える編集用のコピーを作る)をご覧ください |
| `request_delay` | `1.0` | ストアのページを読み込む間隔(秒) |
| `new_days` | `7` | ライブラリの新しいものに **新着** の印をつける日数: `0`(なし)、`1`、`3`、`7`、`14`、`30`(設定の **ライブラリの新着**) |
| `keep_previous` | `1` | アップデートで置き換わるファイルごとに残す以前のバージョンの数: 設定では `0`、`1`、`2`、`3`、`5`(**以前のバージョン**)、ここでは `10` まで |
| `download_retries` | `2` | 失敗したファイルのダウンロードを、あと何回試すか: 設定では `0` から `3`(**失敗したダウンロード**)、ここでは `5` まで |
| `payhip.bot_check_wait` | `180` | Payhipのボットのチェックをあなたが済ませるのを待つ秒数 |
| `jinxxy.item_link_pattern` | | Jinxxyのインベントリのページで、どのリンクがあなたのアイテムか |
| `tags.min_count`, `tags.max_share` | `3`, `0.4` | 言葉がおすすめのタグになる条件: 少なくともこの数の名前にあり、名前のこの割合より多くにはないこと |
| `tags.blocklist` | `[]` | おすすめにしない言葉(タグのパネルの **非表示** と同じ) |

コマンドラインの `--config <file>` では、別の設定ファイルを使います。[コマンドライン](コマンドライン)をご覧ください。
