Hoardは、共有するように頼まない限り、動いているコンピューターにしか応えません。共有すると、スマートフォン、タブレット、ほかのコンピューターからライブラリとダウンロードを見られます。サインイン、更新、ダウンロード、サインアウト、タグや設定の変更、フォルダーを開くことは、これまでどおりHoardを動かしているコンピューターでしかできません。

## 必要なもの

ライブラリとHoardのアクセスキーがネットワークを通るので、共有には次のどちらかが必要です。

- **HTTPS**(Hoardを動かすコンピューター用の証明書つき)。無料のツール[mkcert](https://github.com/FiloSottile/mkcert)で、デバイスが信頼する証明書を作れます。
- デバイスがすでにそのコンピューターにつなぐのに使っている **暗号化されたネットワーク**([Tailscale](https://tailscale.com/)やWireGuardなど)。

## ほかのデバイス向けにHoardを起動する

HTTPSの場合:

```
hoard-cli --host 0.0.0.0 --tls-cert cert.pem --tls-key key.pem
```

Tailscaleなどの暗号化されたネットワークの場合:

```
hoard-cli --host 0.0.0.0 --plain-http
```

(ソースから実行する場合は、`hoard-cli` の代わりに `Hoard.bat` か `./run.sh` です。[コマンドライン](コマンドライン)をご覧ください。)毎回同じポートを使うには `--port 8765`(または空いている任意のポート)を、このコンピューターでもページを開かないようにするには `--no-open` を加えます。Windowsが、ファイアウォールでHoardを通すか聞くことがあります。プライベートネットワークで許可してください。

Hoardは次の2つのアドレスを表示します。

- **ネットワーク上のほかのデバイス:** `https://<このコンピューターのアドレス>:<port>/#key=...`(`--plain-http` では `http://`)。`<このコンピューターのアドレス>` をコンピューターの名前かネットワークアドレスに置き換えて、ほかのデバイスで開きます。
- **Open Hoard at**: 同じアドレスの `127.0.0.1` 版で、このコンピューター用です。

## アクセスキー

ライブラリ、ダウンロード、画像、操作へのリクエストには、Hoardを動かしているコンピューターからでも、すべてそのアドレスのキーが必要です。キーはHoardを起動するたびに新しくなるので、再起動したあとは新しいアドレスを開いてください。デバイスはそれまでそのアドレスのキーを覚えているので、キーなしのページをブックマークしても、その起動の間は使えます。

キーは、それを持たない人を止めますが、暗号化ではありません。そのため、HTTPSか暗号化されたネットワークが必要です。アドレスは信頼できるデバイスとだけ共有してください。

## mkcertで証明書を作る

1. Hoardを動かすコンピューターに[mkcert](https://github.com/FiloSottile/mkcert)をインストールし、`mkcert -install` を実行します。
2. デバイスが使う名前の証明書を作ります。例: `mkcert my-pc my-pc.local 192.168.1.20`。証明書とキーのファイルが作られます。
3. その2つのファイルを `--tls-cert` と `--tls-key` で指定して、Hoardを起動します。
4. ほかの各デバイスで、mkcertのルート証明書(場所は `mkcert -CAROOT` で分かります)をインストールして信頼し、証明書が信頼されるようにします。

これらのオプションは、コマンドラインのリファレンスにも書かれています: [docs/COMMAND-LINE.md](https://github.com/Soloflighter1010/Hoard-Asset-Manager/blob/main/docs/COMMAND-LINE.md#using-hoard-from-other-devices)(英語)。
