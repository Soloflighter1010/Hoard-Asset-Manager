Hoardが保管するものは2つに分かれます。あなたが選んだフォルダーにあるダウンロードと、それ以外のすべてを入れた、あなたのユーザーアカウント専用の非公開のアプリデータフォルダーです。

## Hoardのアプリデータフォルダー

| Windows | macOS | Linux |
|---|---|---|
| `%LOCALAPPDATA%\Hoard` | `~/Library/Application Support/Hoard` | `~/.local/share/Hoard` |

LinuxのFlatpakも `~/.local/share/Hoard` を使います(`~/.var/app` の下の専用フォルダーではありません)。そのため、ソースから実行するHoardとライブラリを共有し、Hoard for Unityからも見つかります。Flatpak専用なのは、Hoardのブラウザーのコピー(`~/.var/app/io.github.soloflighter1010.Hoard/cache`)だけです。

| もの | 何のためか |
|---|---|
| `sign-ins/` | ストアのサインイン。ストアごとに1つのフォルダーで、オペレーティングシステムによって暗号化されます。このフォルダーは決して共有しないでください |
| `config.json` | 設定。[設定](設定)をご覧ください |
| `library.json` | ライブラリの一覧。持っているものの名前、クリエイター、リンク、画像のアドレス |
| `keys/` | Windowsでは、Windowsのアカウントで暗号化したitch.ioのAPIキー。(Macではキーチェーン、Linuxではキーリングにあります。)[ストア](ストア#itchio)をご覧ください |
| `tags.json` | あなたのタグ |
| `picture-looks.json` | 商品の画像の見た目(画像のSHA-256ごとに、64ビットのハッシュ)。2つのストアが別々に保存した1つの商品のコピーをまとめるためです。[ライブラリ](ライブラリ#探す)をご覧ください |
| `asset-updates.json` | 前回の **アップデートを確認** で見つかったもの。ダウンロードしたものごとに、ストアにあって手元にまだないファイル。[ダウンロード](ダウンロード#ダウンロードせずにアップデートを確認する)をご覧ください |
| `marks.json` | アーカイブ、非表示、削除したもの、それに非表示のライブラリのPINと復元ワード(どちらもソルトつきの時間のかかるハッシュとしてだけ) |
| `projects/` | Hoardのウィンドウを開いたUnityプロジェクトごとの小さなレポート(Hoard for Unity 0.4.0以降)。名前とフォルダー、使っているアセット、クレジットの設定。Hoardの **プロジェクト** に表示され、**このプロジェクトを忘れる** で1つ削除します。[Hoard for Unityの使い方](Hoard-for-Unityの使い方#hoardのプロジェクト)をご覧ください |
| `library_folders.json` | ほかのライブラリフォルダーそれぞれに、Hoardが最後に読んだとき何の商品があったか。そのドライブがつながっていない間、同期が手をつけないようにするためです。[ダウンロード](ダウンロード#ほかのドライブのライブラリフォルダー)をご覧ください |
| `integrity.key` | Hoardが記録に封印をするためのキー([封印](#封印)をご覧ください)。あなたのアカウントだけのものです |
| `sealed-files.json` | このインストールが封印した記録。封印が外されたら気づけるようにするためです |
| `cache/thumbs/` | 商品の画像。オフラインでもライブラリを使えるように保存します |
| `cache/inside/` | **中身を見る** がパッケージやzipから読んだ内容とプレビュー。最近中身を見た40個分です(4.0)。[ダウンロード](ダウンロード#ダウンロードの表示)をご覧ください |
| `sets.json` | セット。名前、メモ、写真のリンク、各セットの商品(タグと同じキーで)と、それぞれが何か(4.0、4.2.0)。短縮リンクを作った場合はそのキーと、Hoardがそれを更新・削除するためのトークン(4.3.0)。それに、ほしい物リストと、各商品の前回読み込んだときの価格、変わっていればその前の価格(4.4.0)。[セット](セット#ほしい物リスト)をご覧ください |
| `set-pictures/` | セットのタイル用に選んだ画像(4.2.0)。バックアップには入りません。[セット](セット#セットの画像)をご覧ください |
| `local-pictures/` | 自分のパッケージのタイル用に選んだ画像。Hoardはその横にもコピーします(4.2.0)。[自分のパッケージ](自分のパッケージ#画像)をご覧ください |
| `package-needs.json` | ダウンロードした各パッケージについて、中にあるものと使っているもののID。**必要なもの** がもう一度読まずに分かるようにするためです(4.0) |
| `logs/hoard-<date>_<time>.log` | コンソールなしで動いているときにHoardが出力する内容。何を読んだか、何をダウンロードしたか、エラー(パスワード、Cookie、ページの内容は入りません)。Hoardの起動ごとに1つで、30日間残します(古さにかかわらず最新10個は残します)。20 MBを超えて書き込む回は `-part2` に続きます。設定の **ログフォルダーを開く** でこのフォルダーが開きます。(2.9.2より前は、すべての回で1つの `hoard.log` でした。) |
| `diagnostics/incidents.jsonl` | 最近のエラーとクラッシュのトレースバックの、ローカルだけの非公開の記録。サポートレポートを作るのに使い、自動で送ることはありません |
| `window/` | ウィンドウ自身のストレージ |
| `window-place.json` | 最後に閉じたときのウィンドウの大きさと位置、最大化していたかどうか。次もそこで開くためです。削除すると、ふつうの大きさで中央に開きます |
| `tasks.json` | タスクのウィンドウの、終わったジョブの一覧(最新60件)。それぞれ何をしたか、どうなったか、その進み具合。一覧を空にするには、これを削除するか、タスクで **クリア** を選びます |
| `sync.json` | 前回の同期を始めた日時 |
| `routine.json` | 定期チェックを前回実行した日時(次がいつかを知るため)と、見つかったもののうちまだ見ていないものの数 |
| `update.json` | Hoardが前回アップデートを確認した日時と、見つかった最新のバージョン |
| `updates/` | アップデート中の、ダウンロードして確かめた新しいバージョンのインストーラー。アップデートがインストールされたら削除します |
| `debug/` | トラブル解決用のファイル。`debug` や `probe` を実行したときだけ |

あなたが自分で共有しない限り、これらがコンピューターの外に出ることはありません。

## サポートレポート

**サポートレポートを作成** を選ぶと、Hoardは個人情報を取り除いたZIPを `Documents/Hoard/Support Reports` に書き出し、そのフォルダーを開いて新しいレポートを選択します。このフォルダーはHoardの非公開のアプリデータの外にあるので、ZIPを見つけて添付しやすくなっています。生のログ、サインイン、ライブラリのファイル、そのほかの非公開のアプリデータのファイルはZIPにコピーしません。公開のIssueに添付する前に、レポートの中身を確認してください。

## ダウンロードフォルダー

[設定](設定)でほかを選ばない限り、ドキュメントの中の `Hoard` フォルダーです。商品は `<ストア>/<クリエイター>/<商品>` のフォルダーにあり、Hoardはその横に記録を置きます。

| もの | 何のためか |
|---|---|
| `catalog.json` | ダウンロードしたすべての商品。ストア、名前、クリエイター、フォルダー、ストアのページ、ファイル、タグ。[Hoard for Unity](Hoard-for-Unityの使い方)などのほかのプログラムが読みます |
| `tags.json` | すべてのタグとおすすめのタグと、それがついている商品 |
| `<product>/asset.json` | 1つの商品の同じ情報。その商品のフォルダーにあります |
| `<product>/_thumbnail.*` | 商品の画像 |
| `<Store>/_manifest.json` | そのストアから何をどこにダウンロードしたかの、Hoard自身の記録。編集しないでください |
| `*.part` | 途中で止まったダウンロード。次のダウンロードがその続きから始めます |
| `Payhip/_download-yourself.html` | 2.5.0より前のバージョンが残したもの。Payhipの商品を、自分でダウンロードするための一覧にしていました。HoardはもうPayhipからダウンロードしない([ストア](ストア#payhip)をご覧ください)ので、このページを書くことも読むこともありません。削除してかまいません |

`catalog.json`、`tags.json`、`asset.json` は、ほかのプログラムが読むために書いていて、整ったテキスト、ふつうの相対パス、商品自身のストアへのリンクだけであることを約束しています。正確な形式は[docs/DATA-FORMATS.md](https://github.com/Soloflighter1010/Hoard-Asset-Manager/blob/main/docs/DATA-FORMATS.md)(英語)にあります。

## 封印

Hoardが書くすべての記録(ライブラリの一覧と印、ダウンロードフォルダーの各ストアの `_manifest.json`、`catalog.json`、`tags.json`、すべての `asset.json`)には、`integrity.key` で作った封印がついています。記録がHoard以外のものに変更されると、封印でそれが分かり、Hoardは次のようにします。

- それを伝え、変更されたファイルのコピーを見られるように残します(`_manifest.changed-<date>.json` など)。
- 記録は残しますが、リンクは残さず、次の更新や同期のときにストアからリンクを取得し直します(編集された `marks.json` は、選択は残しますが、非表示のライブラリのPINは消します)。

`hoard-cli verify` は、ダウンロードフォルダーのすべての記録をチェックしてから、カタログのファイルを作り直します。壊れたファイル(正しいJSONでないなど)は `<name>.damaged-<date>.json` として残し、Hoardはそれなしで続けます。

## 1つのダウンロードフォルダーを2台のコンピューターで

それぞれのコンピューターのHoardは、自分のキーで記録に封印をするので、相手の記録を確かめられていないもの(「saved by Hoard on another computer」)として扱い、ストアのリンクを取得し直します。NASなどで1つのダウンロードフォルダーを共有するには、片方のコンピューターのHoardのアプリデータフォルダーにある `integrity.key` を、もう片方の同じ場所にコピーします。

## バックアップと、新しいコンピューターへの引っ越し

- **ダウンロードフォルダー** は、Hoardの記録が横にある、ふつうのファイルです。まるごとバックアップしたり移動したりしてください。
- **Hoardのアプリデータフォルダー** には、設定、ライブラリの一覧、タグ、印、`integrity.key` があります。新しいコンピューターの同じ場所にコピーすると、封印が有効なまま引き継げます。
- **サインインは移せません。** 作ったコンピューターのあなたのアカウント用に暗号化されているので、新しいコンピューターではストアにもう一度サインインしてください。

新しいコンピューターでダウンロードフォルダーが別の場所にある場合は、[設定](設定)で選んでください。

## すべてを削除する

1. **ストア** で **すべてのストアからサインアウト** を選びます。できる場合はセッションを終え、すべてのストアのアイテムをライブラリから消します。
2. Hoardをアンインストールします([Hoardのインストール](Hoardのインストール#アンインストール)をご覧ください。Macではアプリケーションからゴミ箱にドラッグ、Flatpakでは `flatpak uninstall --delete-data io.github.soloflighter1010.Hoard`)。
3. Hoardのアプリデータフォルダー(上)と、ファイルがいらなければダウンロードフォルダーを削除します。
4. Hoard専用のブラウザーをダウンロードしていた場合は、それも削除します。Windowsでは `%LOCALAPPDATA%\ms-playwright`、Macでは `~/Library/Caches/ms-playwright`、Linuxでは `~/.cache/ms-playwright` です(Flatpakのものは `--delete-data` で消えます)。Playwrightを使うほかのプログラムと共有していることがあります。

すべての一覧と、それぞれの理由は[PRIVACY.md](https://github.com/Soloflighter1010/Hoard-Asset-Manager/blob/main/PRIVACY.md)(英語)にあります。
