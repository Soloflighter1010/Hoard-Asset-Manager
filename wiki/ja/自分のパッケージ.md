Hoardは、買ったものの横に、自分で作ったものも保管します。プロジェクト間でテクスチャやマテリアルを移すため、または作品を届ける相手に渡すために作ったパッケージは、**ローカル** に入ります。ダウンロードしたものと同じように、タグをつけ、検索し、Unityにインポートできます。

## 追加する

**ローカル**(上のバー、またはダウンロードの **ローカル** タブ)を開き、**自分のものを追加** を選びます。

1. **フォルダー…** または **ファイル…** で選ぶか、フルパスを入力します(例: `D:\Packages\My Textures`)。(Hoard専用のウィンドウではなくWebブラウザーで使っている場合は、選択画面がないので、パスを入力してください。)
2. 名前(空のままにするとフォルダーの名前)、作った人(指定しなければ **あなた**)、それに必要なら、だれのため、何のためのものか(依頼、プロジェクト、友だち)を入力します。
3. Hoardがどう保管するかを選びます。前回選んだものが最初に選ばれています。

| | **Hoardにコピーする** | **今の場所のまま一覧にする** |
|---|---|---|
| ファイルの場所 | ダウンロードフォルダーの中の `Local` にコピー | 今ある場所 |
| あとで元のファイルを変えると | コピーは変わらない | Hoardが一覧にするのはそれ(追加・削除したファイルを反映するには **再スキャン**) |
| 定期チェック([ダウンロードをチェックする](ダウンロード#ダウンロードをチェックする)) | ダウンロードと同じくチェックする | 手をつけない(あなたの作業フォルダーなので) |
| Hoardがそこに書き込むもの | そのコピーと、横に `asset.json` | 何も書き込まない |
| **Remove from Local**(ローカルから削除) | Hoardのコピーを削除する(コピーしたファイルだけ) | 忘れるだけで、フォルダーの中のものには手をつけない |
| 画像 | 選んだもの、なければ中の画像の1つ(プレビューらしい名前のものが優先) | 選んだもの、なければ中の画像の1つを `Local` にコピーしたもの(**再スキャン** で作り直す) |
| ディスク容量 | 同じだけ余分に使う | その画像の分だけ |

1つのファイルはコピーしかできません。今の場所のまま一覧にしたいときは、そのフォルダーを選んでください。フォルダーの中のリンク(ショートカット)は除き、フォルダー自体がリンクの場合は一覧にできません。ダウンロードフォルダーを中に含むフォルダー(ドキュメントフォルダー全体など)は追加できません。Hoard自身のダウンロードがローカルに入ってしまうからです。システムが扱えない名前のファイルは除き、残りはそのまま追加します。

大きなフォルダーのコピーには時間がかかります。タスクとして実行されるので、タスクで進み具合が分かります。

### ローカルの同期フォルダー

[設定](設定)の **ローカルの同期フォルダー**(5.2.0)でフォルダーを選ぶと、そこに入れたものが自動でここに追加されます。中のフォルダーはその場所のまま一覧に入り、中のファイルはコピーされます。100 MBを超えるファイルや1 GBを超えるフォルダーは追加しません(設定にどれかが表示されます)。このコンピューターのドライブにある必要があり、ネットワークドライブやNASは使えません。同期フォルダーから取り出すとタイルにそう表示され、**ローカルから削除** を選ぶまではローカルに残ります。

Windowsでは、エクスプローラーで同期フォルダーにHoard専用のアイコンが付き、どこでもファイルやフォルダーを右クリックすると **Hoardに追加** が出ます(Windows 11では **その他のオプションを確認** の中)。ファイルは同期フォルダーにコピーされ、フォルダーはその場所のままここに一覧されます。同期フォルダーを右クリックすると **今すぐHoardと同期** と **Hoardで開く** があります。設定の **エクスプローラーに表示** でオフにできます。

Mac(5.2.0 beta 14)ではFinderで同じことができます。同期フォルダーにHoardのアイコンが付き、**Hoardに追加**、**今すぐHoardと同期**、**Hoardで開く** はクイックアクションとして、右クリックの **クイックアクション** の中に出ます。Linuxでは、GNOME ファイル、Dolphin、Nemoでフォルダーにアイコンが付き、入っているファイルマネージャーに項目が出ます。GNOME ファイルでは **スクリプト** の中、DolphinとNemoではほかの項目と並んで出ます。Flatpak版でアイコンが出るのはDolphinだけです(GNOME ファイルとNemoがフォルダーのアイコンを保存する場所に、サンドボックスからは届きません)。設定の **Finderに表示** または **ファイルマネージャーに表示** でオフにできます。Hoardをアンインストールすると、次に項目を選んだときに項目が自分で取り除かれます。

### Unityパッケージを作る

ローカルのアイテムの詳細にある **Unityパッケージを作る**(5.2.0)で、Unityを開かずに`.unitypackage`を作ります。編集用コピーのフォルダーの **Unity packages** に作られ、そのフォルダーで表示されます。ファイルは`Assets/<アイテムの名前>/`の下に入ります。横に自分の`.meta`があるファイル(Unityのプロジェクトからコピーしたもの)はそれを使うので、参照しているものからそのまま見つかります。ない場合は新しいIDになり、Unityがいつもの取り込み設定を付けます。Hoardは新しいIDになったものと、入れなかったもの(隠しファイル、~で終わるファイル、対応するもののない`.meta`)を示します。アイテム自身のフォルダーには何も書き込みません。詳しくは[作るときの調査メモ](https://github.com/Soloflighter1010/Hoard-Asset-Manager/blob/main/docs/UNITYPACKAGE-FROM-LOCAL.md)をご覧ください。

### フォルダーの入ったフォルダー

すでに、たとえばクリエイターごとのフォルダーの中に商品ごとのフォルダーがある形で整理していますか? **中のフォルダー** で、**中のフォルダーをそれぞれパッケージにする**、または2段や3段下を選びます。その深さにあるフォルダーがそれぞれ1つのパッケージになり、フォルダーの名前がつきます。2段下からは、その上のフォルダーが作った人になります(代わりにすべてに同じ名前を使うには、**制作者** に名前を入力します)。**追加** を選ぶ前に、Hoardが何を追加するかを一覧にします。上の階層のフォルダーにあるファイルは除き(一覧にその数が出ます)、Hoard自身のダウンロードフォルダーは決して含まれません。一度に500個まで追加できます。選んだとおりにまとめてコピーまたは一覧にし、**誰のため、何のためのものか** はそのすべてに適用されます。あとで同じフォルダーをもう一度追加すると、新しいフォルダーだけを追加します。すでにローカルにあるものは一覧に印がつき、そのままになります。(3.0のベータ版、ベータ6より前に追加したパッケージは、この方法では見分けられません。)

### KonoAssetから

[KonoAsset](https://github.com/siloneco/KonoAsset)から移ってきましたか? 設定の「ほかのツールから取り込む」にある **KonoAssetから取り込む...**(初めてならセットアップアシスタントの最後のステップでも)を選び、KonoAssetのデータフォルダーを選びます。`metadata`、`data`、`images` が入っているフォルダーです(場所はKonoAssetの設定でわかります)。KonoAssetを起動している必要も、インストールしている必要もありません。何かが変わる前に、取り込むと何が起きるかをHoardが表示します。そのあと **取り込む** か **キャンセル** を選びます。

- BOOTHの商品がHoardのライブラリにあるアセットは、その商品と照らし合わせます。残りは今の場所のまま一覧にしたローカルの商品になります。ファイルはKonoAssetの `data` フォルダーに置いたままで、KonoAssetの画像がそれぞれの選んだ画像になります。
- タグは自分のタグになり、カテゴリーと、衣装が対応するアバターもタグになります。アバターはアバター、ワールドオブジェクトはワールドとして記録します(自分で種類を決めていれば、そのままです)。
- メモは商品のメモ([ライブラリ](ライブラリ#アイテムの詳細)をご覧ください)になり、その後ろに必要なもの(「Needs: ...」)と、ローカルの商品ならBOOTHのページが続きます。すでに書いたメモはそのまま残ります。
- ファイルがなく、ライブラリにもないアセットは取り込まず、名前を表示します。

HoardはKonoAssetのフォルダーを読み取るだけで、中のものを書き込んだり、移動したり、削除したりはしません。取り込んだものは覚えておくので(アプリデータフォルダーの `konoasset.json`)、あとでもう一度取り込むと新しいものだけを追加します。KonoAsset 1.0以降が書き出す一覧を読み取れます。

### BB's Library Managerから

[BB's Library Manager](https://github.com/BunBnnuy/BBLM)から移ってきましたか?設定の「ほかのツールから取り込む」で **BB's Library Managerから取り込む...** を選び、そのルートフォルダーを選びます。商品ごとのフォルダー(それぞれに `meta.json` があります)が入ったフォルダーです(場所はその設定に書かれています)。BB's Library Managerは起動していなくても、インストールされていなくてもかまいません。何かを変える前に、取り込むと何が起きるかをHoardが伝えます。そのあと **取り込む** か **キャンセル** を選びます(5.2.0 beta 13)。

- BOOTHの商品がHoardのライブラリにあるものは、その商品と照らし合わせます。フォルダーがもうローカルにあるもの(**自分のものを追加** で追加したものなど)は、そのローカルの商品と照らし合わせます。残りは今の場所のまま一覧にしたローカルの商品になります。ファイルはそのフォルダーに置いたままで、それぞれの `thumbnail.png` が選んだ画像になり、入手元のページがストアの商品ページになります([変更する](#変更する)をご覧ください)。BB's Library Manager自身の `meta.json` と画像は、ファイルに含めません。ローカルの商品と同じ名前のものは、名前のあとに「BBLM」とそのIDが付きます。
- タグはあなたのタグになり、成人向けのマークが付いた商品には18+のマークが付きます。ただし、**成人向けではない** と自分で選んだものはそのままです(あなたの選択が優先されます)。
- まだダウンロード中の商品、ファイルがなくライブラリにもない商品、一覧にできない商品(理由付き)は取り込まず、名前を伝えます。

Hoardはそのフォルダーを読み取るだけで、中のものを書き込んだり、移動したり、削除したりはしません。取り込んだものは覚えておくので(アプリデータフォルダーの `bblm.json`)、あとでもう一度取り込むと新しいものだけを追加します。ローカルから削除した商品や、ルートフォルダーごと移動した商品は、もう一度取り込まれます。タスクの **停止** で商品と商品の間で止まり、何も取り込みません。

## 画像

アイテムのタイルには、最初はその中の画像の1つが表示されます。ほかの画像にするには、アイテムを開いて **画像を選ぶ...** を選びます。コンピューター上のPNG、JPEG、WebP、GIFのどれでもよく、幅は最大640ピクセルにします(静止画として、PNGかJPEGで保存します)。Hoardはそれをアプリデータフォルダーの `local-pictures` に保管し、アイテム用のHoard自身のフォルダーに `_thumbnail.png` または `.jpg` としてコピーします。コピーしたアイテムならそのコピーの横、今の場所のまま一覧にしたアイテムなら `Local/_linked/...` で、あなたのフォルダーには何も書き込みません。Hoard for Unityにも表示されます。**再スキャン** しても残ります。**画像を外す**(今の場所のまま一覧にしたアイテムでは **中にある画像を使う**)で、中の画像に戻ります。中に `_thumbnail` という画像があるアイテムはそれを表示します。その場合はそのファイルを変えてください。

## 変更する

アイテムの詳細の **編集...** で、名前、作った人、メモ、ストアの商品ページを変えられます(5.2.0 beta 13)。商品ページは、Booth、Gumroad、Jinxxy、Payhip、itch.ioの商品のページです(自分でダウンロードした無料のBOOTHの商品など)。名前を変えても、タグ、メモ、そのアイテムについての選択(非表示、18+)、セットの中の場所は一緒についていきます。ファイルとフォルダーには手を付けません。そのあとは詳細からそのページを開けます(**Boothで開く** など)。ローカルのアイテムの名前はそれぞれ別で、ほかのアイテムと同じ名前にはできません。

商品ページがあれば、**ページから入れる** でそのページを(誰でも見られる形で)読み込み、名前、作った人、クリエイターが付けたタグ(候補として)、画像を入れます。ストアで成人向けとされている商品には18+のマークが付きます。アイテムに商品ページを入れるとすぐ、入れるかどうかをHoardがたずねます。

## 使う

- ローカルのアイテムは、ダウンロードの **ローカル** にあり、タグ、検索、**編集用のコピーを作る** が使えます。ストアの商品ページがあるものができると、ローカルにはストアごとのタブと、ページのないもののタブができます(5.2.0 beta 13)。
- **Hoard for Unity** は、**Local** にそれらを一覧にし(0.4.0以降)、ほかのダウンロードと同じように `.unitypackage` ファイルをインポートします。クレジットの一覧にも、プロジェクトに入っていれば含まれます。
- 今の場所のまま一覧にしたアイテムは、このコンピューターのHoard自身の封印された記録からしか信頼されません。`Local/_manifest.json` がほかの何かによって変更されると、もう一度追加するまで、Hoardも Hoard for Unityも、そこに書かれたフォルダーを使わなくなります。
