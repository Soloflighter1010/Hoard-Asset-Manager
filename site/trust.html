How you can trust Hoard

Hoard signs in to the stores you buy from, so it's fair to ask why you should let it. You don't have to take our word for anything here: each point links to where you can check it yourself.

What you can check

  • Every line is public

    Hoard is open source under the MIT license. All of its code, its tests and the way each release is built are on GitHub, along with the history of every change, so anyone can read exactly what it does.

    The code · MIT license · Every change

  • Your passwords never reach it

    You sign in on each store's own page, in a browser window of its own. Hoard keeps only the "stay signed in" pass the store hands out, encrypted by your Windows account, your Mac's Keychain or your Linux keyring, and each store's is kept apart.

    How Hoard protects you · How it works

  • Nothing is sent to us

    There's no Hoard account and no Hoard server: no tracking, no analytics, no ads. Hoard talks only to the stores you use, the hosts their files and pictures come from, and GitHub when you check for updates. Support reports are made on your computer, with your details taken out, and only shared if you share them.

    Privacy policy · Who Hoard talks to

  • Downloads you can check

    Each release is built by GitHub from the public code, by a workflow anyone can read, with a signed record of how (build provenance) and a checksum for every file. Every file is scanned by VirusTotal before the release is published, with the report linked in its notes. The Windows programs are code-signed.

    The release workflow · Checking a download · About build provenance · Code signing · Releases

  • Checked on every change

    Every change runs Hoard's tests on Windows and Linux, its security tests included, and builds the apps, in the open on GitHub. GitHub's CodeQL scans each change for security problems. Hoard's dependencies are pinned to exact versions and checked against recorded fingerprints when they're installed.

    The tests that run · Recent runs · About CodeQL · Pinned dependencies

  • Tested by people, too

    Each version goes to testers first, as a beta, who try it on their own libraries and report what breaks. You can join them, or follow along: every bug report and request is public.

    Our testers · Issues · Discussions

  • Made with AI help, in the open

    Much of Hoard is written with Claude, an AI model, under the maintainer's direction. Hoard itself has no AI in it, and never sends your library to an AI service. The disclosure says exactly how it's used.

    AI disclosure

  • What no app can promise

    Hoard can't protect you from malware already on your computer, from someone with administrator access to it, or from problems on the stores' own sites. The macOS packages aren't signed by Apple yet, and the hidden library is a privacy screen, not encryption. The security policy lists these limits in full.

    What Hoard can't protect against

Found a security problem? Please report it privately, from the repository's Security tab (how), so it can be fixed before it's public. Anything else, open an issue.
