A bookmark for Payhip

Save for Hoard

On a Payhip shop's library page, this bookmark saves every page of your library there as one file for Hoard to import, instead of saving each page by hand.

Save for Hoard

Drag it to your browser's bookmarks bar. It only does something on a Payhip shop's library page.

Using it

  1. Add it to your bookmarks bar.

    Drag Save for Hoard, above, to the bar. Don't see the bar? Press Ctrl+Shift+B (Cmd+Shift+B on a Mac) to show it. Or right-click the button, copy its address (Copy link address, or Copy Link in Firefox and Safari), make a new bookmark and paste it as the bookmark's address.

  2. Open a shop's library page.

    That's the shop's address followed by /b-account, such as myshop.store/b-account. Sign in there if it asks.

  3. Choose the bookmark.

    It reads every page of your library on that shop and saves them as one file, Payhip library - <shop>.html, in your downloads. Do the same on each shop you've bought from.

  4. Import the files in Hoard.

    In Stores, choose Import pages and pick them all, or drop them on Hoard's window.

What it does, and doesn't

  • It runs only when you choose it, on the page you're on. Anywhere but a shop's library page, it just says to open one.
  • It reads that shop's own library pages, as you, one after another, and nothing else.
  • It sends nothing anywhere. The file goes to your downloads, and Hoard reads it only when you import it.
  • It's the same bookmark Hoard offers under Stores › Import saved pages (where copy it copies it too), and its code is in Hoard's hoard/web/library.html, where it's called PAYHIP_SAVER.

Why a page of its own? Hoard opens in a window of its own, and a link can't be dragged from it into your browser's bookmarks bar. More on Payhip in Hoard: Stores.
