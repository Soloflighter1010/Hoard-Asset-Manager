Thank you, testers

Every release of Hoard went to these people first. They tried it on their own libraries, found what broke, and told us what got in the way, so it would work for everyone else.

Betas of the next version come out on GitHub as pre-releases, titled "Hoard 3.1.0 beta 1" and so on. To get each one as an update, turn on Get beta updates in Hoard's Settings, under Updates; you're offered the finished version when it's out.

Want to help test what's next? Say hello in Discussions, or report a problem you've found.
