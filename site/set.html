    What's in it

      Each picture comes from the product's store, and each link opens the product there. Prices and what's in each product are as the store shows them now.

      Use it in Hoard

      Have Hoard? Open Sets, choose Add a shared set, and paste this page's link (or its code, which Hoard 4.2 can add too). Products you already own show as yours, and the rest show where to buy them. Hoard for Unity can then import the set's products together.

      The set is stored in this page's link, after the “#”. Your browser never sends that part anywhere, so this site never sees the set, and Hoard keeps no copy of it.
