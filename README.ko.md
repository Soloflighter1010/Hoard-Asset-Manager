<a id="install-windows"></a>
## 설치 (Windows)

1. [Releases](https://github.com/Soloflighter1010/Hoard-Asset-Manager/releases/latest)에서 **`Hoard-Setup-<버전>.exe`**를 다운로드해서 실행하세요. 내 계정에만 설치되고, 관리자 확인 창은 뜨지 않아요. 시작 메뉴에 Hoard가 추가돼요.
2. 릴리스 직후에는 한동안 **"Windows의 PC 보호"** 창이 뜰 수 있어요. Hoard는 코드 서명이 되어 있지만(**추가 정보**를 고르면 게시자로 Hoard 관리자가 나와요), 새 게시자는 먼저 Microsoft의 신뢰를 쌓아야 해요. [CODE_SIGNING.md](CODE_SIGNING.md)(영어)를 보세요. **실행**을 고르세요. 다운로드한 파일이 이 프로젝트의 GitHub 빌드에서 왔는지 확인하려면: `gh attestation verify Hoard-Setup-<버전>.exe -R Soloflighter1010/Hoard-Asset-Manager`
3. 시작 메뉴에서 **Hoard**를 여세요. 전용 창에서 열려요. 짧은 설정 도우미가 언어, 쓰는 스토어, 각 스토어 로그인, Payhip 상점, 다운로드 저장 위치를 차례로 안내해요. **설정**의 **Hoard 다시 설정**에서 언제든 다시 할 수 있어요.

**업데이트:** **설정**의 **업데이트**에서 **지금 확인**을 고르고, 새 버전으로 **업데이트**를 고르세요. Hoard가 다운로드해서 릴리스의 체크섬과 맞춰 본 뒤, 닫고 설치하고 다시 열어요. (**업데이트 자동 확인**을 켜면 새 버전이 나왔을 때 알려줘요. 켜지 않으면 꺼져 있어요.) 새 설치 파일을 직접 실행해도 돼요. 먼저 제거할 필요는 없어요. 설정, 라이브러리, 로그인, 태그는 Hoard의 앱 데이터 폴더(`%LOCALAPPDATA%\Hoard`)에, 다운로드는 다운로드 폴더에 있어서 설치, 업데이트, 제거로 지워지지 않아요.

설치 프로그램이 싫다면 `Hoard-<버전>-windows.zip`도 같은 앱이에요. 아무 곳에나 압축을 풀고 `Hoard.exe`를 실행하세요. Hoard 창은 Microsoft Edge WebView2를 써요(Windows 11에 포함되어 있고, Windows 10에서도 자동으로 최신으로 유지돼요). WebView2가 없으면 대신 웹 브라우저에서 열려요(종료는 **설정**에서).

<a id="install-macos-linux"></a>
## 설치 (macOS, Linux)

- **macOS 11 이상:** [Releases](https://github.com/Soloflighter1010/Hoard-Asset-Manager/releases/latest)에서 `Hoard-<버전>-macos-apple-silicon.pkg`(M 시리즈 Mac) 또는 `Hoard-<버전>-macos-intel.pkg`를 다운로드해서 여세요. 아직 Apple 서명이 없어서 처음에는 열리지 않아요. **완료**를 고른 뒤 **시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기**를 고르세요. Hoard는 **응용 프로그램**에 들어가요.
- **Linux (x86_64):** `Hoard-<버전>-linux-x86_64.flatpak`을 다운로드해서 소프트웨어 센터로 열거나, `flatpak install --user Hoard-<버전>-linux-x86_64.flatpak`을 실행하세요. [Flathub](https://flathub.org/setup)의 GNOME 런타임을 써요.

둘 다 Hoard 전용 창에서 열려요. 업데이트하려면 새 파일을 같은 방법으로 설치하세요(어떤 파일인지는 **설정 › 업데이트**에 나와요). 자세한 내용: [Installing Hoard](https://github.com/Soloflighter1010/Hoard-Asset-Manager/wiki/Installing-Hoard)(영어)

**소스에서 (어떤 OS든):** [Python 3.10 이상](https://www.python.org/downloads/)을 설치하고, `Hoard-<버전>.zip`을 다운로드해서 압축을 푼 뒤 `Hoard.bat`(Windows) 또는 `./run.sh`를 실행하세요. 전용 Python 환경을 만들고(모든 패키지를 미리 기록된 지문과 맞춰 봐요) Hoard를 열어요.

**Hoard 1.x에서 옮겨 오나요?** 로그인과 태그는 자동으로 넘어와요. 라이브러리 목록과 다운로드 폴더는 설정 도우미에서 1.x를 실행하던 폴더를 고르면 옮겨져요.

<a id="using-hoard"></a>
## Hoard 사용법

- **동기화**(오른쪽 위)는 쓰는 스토어마다 가진 것을 읽고, 새로운 것을 한 번에 다운로드해요. 진행 상황이 보이고, **중지**로 안전하게 멈출 수 있어요.
- **스토어**(오른쪽 위): 전용 브라우저 창에서 스토어마다 한 번만 로그인해요. **새로고침**은 구매한 것을 읽어요. **다운로드**는 그 스토어의 새로운 것을 모두 로컬에 저장하고, **새로운 것 모두 다운로드**는 모든 스토어를 한 번에 해요.
- **페이지 가져오기**(**스토어** 안)는 평소 브라우저에서 저장한 라이브러리 페이지(Ctrl+S, "웹페이지, 단일 파일")를 대신 읽어요. 몇 개든 한 번에 고를 수 있고, 폴더째로도, 창에 끌어다 놓아도 돼요. 스토어가 새로고침을 막을 때나 그곳에 로그인하고 싶지 않을 때 편해요.
- **라이브러리**에는 가진 모든 것이 나와요. 상품을 열면 상세를 보고, 태그를 붙이고, 스토어 페이지를 열고, **다운로드**할 수 있어요. 이미 가진 것에는 **디스크에 있음**이 표시되고, 다운로드로 가는 링크와 그림 위에 작은 다운로드 표시가 붙어요. 왼쪽의 **다운로드함**과 **아직 다운로드 안 함**으로 그것만 볼 수 있어요.
- **작업**에는 실행 중인 것, 차례를 기다리는 것, 끝난 것이 진행 상황과 함께 나와요. 다른 작업 중에 무언가를 시작하면 거절되지 않고 대기열에 들어가요. 작업에서 대기열에서 뺄 수도 있어요.
- **태그**, **스토어**, **설정**은 옮기고 크기를 바꿀 수 있는 창으로 열리고, 나란히 열어 둘 수 있어요. 설정은 바꾸는 즉시 저장돼요.
- **다운로드**에는 컴퓨터에 있는 것이 파일, 크기, 폴더와 함께 나와요. **새것 다운로드**는 새로운 것이나 업데이트된 것을 가져오고, 진행 상황이 보여요. **중지**로 안전하게 멈추고, 다음에 이어서 해요. **업데이트 확인**(**업데이트** 안)은 다운로드한 뒤 제작자가 추가하거나 바꾼 것을 아무것도 다운로드하지 않고 목록으로 보여줘요. 그다음 하나씩 **업데이트**하거나 **모두 업데이트**하세요. **내용 보기**(상품 파일 목록에서 `.unitypackage`나 `.zip` 옆)는 아무것도 풀지 않고 안의 파일을 폴더별로, Unity가 저장해 둔 미리보기와 함께 보여줘요. `.zip`이면 안에 든 각 Unity 패키지의 내용도 볼 수 있어요. **필요한 것**(상품 상세)에는 그 패키지가 쓰지만 안에 들어 있지 않은 것이 나와요. lilToon, Poiyomi, Modular Avatar 같은 셰이더와 도구, 그리고 의상이 맞춰진 아바타 본체처럼 가진 다른 상품이에요.
- **Payhip**은 목록만 보여주고 다운로드하지 않아요. Payhip에서 산 모든 것을 상품마다 다운로드 페이지와 함께 보여주고, 파일은 Payhip에서 직접 다운로드하세요. Payhip은 구매품을 구매한 상점마다 라이브러리 페이지 하나로 보관해요. 가장 쉬운 방법은 상점마다 라이브러리 페이지(모든 페이지)를 저장해서 한꺼번에 가져오는 거예요. 아직 추가하지 않은 상점은 확인하면 추가돼요. 또는 **설정**의 **Payhip 상점**에 상점을 추가하고(주소는 구매 이메일에 있어요) 새로고침하세요. Payhip은 자동화된 브라우저를 확인하기 때문에, 확인을 마칠 수 있는 창이 열려요.
- **itch.io**는 itch.io 공식 앱처럼 비밀번호 대신 API 키로 로그인해요(itch.io 웹사이트는 자동화된 브라우저의 로그인을 허용하지 않아요). **스토어**의 itch.io 줄에서 **API 키 추가**를 고르면, Hoard가 키 만드는 곳을 알려주고, itch.io에서 확인한 뒤, OS의 보호를 받아 보관해요. 그다음 itch.io 라이브러리에 있는 모든 것(구매한 것, 번들이나 "원하는 가격" 페이지에서 받은 것)을 읽고 다운로드하며, 파일마다 itch.io의 체크섬과 맞춰 봐요. 2.5.0 이전에 Hoard를 설정했다면 먼저 **설정**에서 itch.io를 켜세요. 게임 빌드(제작자가 Windows, macOS, Linux, Android용으로 표시한 파일)는 **설정**에서 게임 빌드 건너뛰기를 끄지 않는 한 건너뛰어서, 게임이 든 라이브러리도 드라이브를 가득 채우지 않아요.
- **저장된 비밀번호 없이 로그인하기:** Hoard 창은 전용 브라우저라서 평소 브라우저에 저장한 비밀번호가 없어요. 도우미가 Chrome, Edge, Firefox, Safari, 비밀번호 관리자에서 비밀번호를 찾아 복사하는 방법을 알려줘요. 스토어가 로그인이나 확인 링크를 이메일로 보내면, 클릭하지 말고 도우미에 붙여 넣으세요. Hoard 창에서 열려요.
- **보관, 삭제한 것, 숨긴 것**(왼쪽): 상품을 열거나 **선택**으로 여러 개를 골라, 방해되는 오래된 상품은 **보관**하고(Gumroad에서 보관한 구매품도 여기서 시작해요), 상관없는 것은 **삭제**하거나(새로고침해도 돌아오지 않아요. **삭제한 것**에서 완전히 지울 수 있어요), PIN으로 잠가 **숨기기**할 수 있어요. 숨긴 것은 그 브라우저에서 잠금을 풀 때까지 다운로드를 포함해 어디에도 나오지 않아요. 이건 사생활 가리개일 뿐 암호화가 아니에요. 디스크의 파일은 그대로 평범한 파일이에요. PIN을 정하면 Hoard가 복구 단어 6개를 한 번만 보여줘요. 꼭 적어 두세요. 숨긴 것을 잃지 않고 잊어버린 PIN을 재설정하는 방법이에요.
- **설정**에서는 다운로드 저장 위치(따로 고르지 않으면 문서 안의 `Hoard` 폴더), 포함할 스토어, 스토어 로그인에 쓸 브라우저(따로 고르지 않으면 Microsoft Edge), 화면 언어를 고를 수 있어요.
- **태그**는 두 화면에서 똑같이 써요. 아래 [태그](#tags)를 보세요.

<a id="hoard-in-unity"></a>
## Unity에서 Hoard 쓰기

**Hoard for Unity**는 Hoard가 다운로드한 것을 Unity 에디터로 가져와요. **Hoard › Open Hoard**(Unity 메뉴 막대에 있는 전용 메뉴)를 열면 썸네일과 함께 다운로드를 검색하고, 열린 프로젝트에 이미 들어 있는 상품을 확인하고(각 `.unitypackage` 안의 에셋 GUID로 읽어요), Unity 자체 가져오기 창으로 **Import**할 수 있어요. 다시 다운로드할 필요가 없어요. 상품이 `.zip`에 들어 있어도(Booth 상품에 많아요) 그 `.zip` 아래에 나오고, **Import**는 그 패키지만 풀어서 같은 창을 열어요. 이 프로젝트에 없는 것(셰이더, 도구, 아바타 본체)이 필요한 상품은 그걸 알려 주고, **Import** 전에 물어봐요. Hoard의 카탈로그를 읽기만 하고, Hoard의 봉인을 확인하며, 에디터 전용이라 업로드하는 것에는 아무것도 들어가지 않아요. (Hoard for Unity 화면은 아직 영어예요.)

VRChat Creator Companion에서 추가하려면 [Hoard 웹사이트](https://hoard.furryup.link/#unity)를 열고 **Add to VCC**를 고르거나, **Settings › Packages › Add Repository**에서 `https://hoard.furryup.link/index.json`을 붙여 넣으세요. 그다음 프로젝트에 **Hoard**를 추가하세요. VCC 없이 쓰려면 [Releases](https://github.com/Soloflighter1010/Hoard-Asset-Manager/releases?q=unity-v&expanded=true) 페이지의 릴리스("Hoard for Unity ...", 태그 `unity-v...`)에서 `.unitypackage`를 가져오세요. 자세한 내용은 [Packages/soloflighter.hoard/README.md](Packages/soloflighter.hoard/README.md)(영어)에 있어요.

스크립트나 데스크톱이 없는 컴퓨터를 위해 모든 기능을 명령줄에서도 쓸 수 있어요: [docs/COMMAND-LINE.md](docs/COMMAND-LINE.md)(영어)

<a id="keeping-you-safe"></a>
## Hoard가 나를 지키는 방법

나를 지켜 주는 것들을 쉬운 말로 설명할게요. 기술적인 내용은 [SECURITY.md](SECURITY.md)(영어)에 있어요.

**스토어 계정**
- **Hoard는 비밀번호를 절대 보지 않아요.** 로그인은 스토어 자체 페이지에서 해요. Hoard가 보관하는 건 스토어가 주는 "로그인 상태 유지" 통행증뿐이고, 평소 브라우저가 보관하는 것과 같아요.
- **그 통행증은 내 컴퓨터로 잠겨 있어요.** Windows 계정, Mac의 키체인 또는 Linux 키링으로 암호화되어서, Hoard 파일을 다른 컴퓨터로 복사해도 아무도 쓸 수 없어요.
- **스토어마다 따로 보관해요.** Booth 로그인과 Gumroad 로그인은 절대 섞이지 않아요.
- **로그아웃하면 정말 로그아웃돼요.** Hoard가 스토어에 세션 종료를 요청하고, 저장한 것을 지우고, 남은 게 없는지 확인한 뒤 무엇을 했는지 알려줘요. 그 스토어의 상품도 라이브러리에서 빠져서, 다음에 로그인하는 사람은 내가 산 것을 볼 수 없어요. 다운로드한 파일은 남아요.

**내 컴퓨터**
- **Hoard 페이지는 나만 볼 수 있어요.** Hoard를 실행 중인 컴퓨터에서만 열려요. 다른 기기와 공유하려면 직접 켜야 하고, 그때는 보안 연결과 키가 필요해요.
- **웹사이트가 Hoard를 악용할 수 없어요.** 다른 사이트는 Hoard 페이지를 읽거나, 버튼을 누르거나, 자기 페이지 안에 숨길 수 없어요.
- **스토어에서 온 것은 내 컴퓨터에서 실행되지 않아요.** 스토어의 이름, 링크, 그림은 그냥 텍스트와 평범한 이미지로 보여주고, 코드로 다루지 않아요.
- **다운로드는 정해진 곳에만 가요.** 모든 다운로드와 스토어 요청은 단계마다 확인돼요. 보안 연결만 쓰고, 내 컴퓨터나 집 네트워크로는 절대 가지 않으며, 스토어 로그인 정보는 그 스토어에만 보내고 파일을 호스팅하는 서버로는 보내지 않아요.
- **집 네트워크에는 들어가지 않아요.** 상품 그림은 공개 인터넷에서만 가져오고, 공유기나 NAS, 다른 기기에서는 가져오지 않아요.

**내 파일**
- **다운로드는 다운로드 폴더 안에만 저장돼요.** 스토어가 보낸 것도, Hoard 기록에 적힌 것도 다른 곳에 파일을 저장하게 만들 수 없어요.
- **파일 이름으로 다른 것인 척할 수 없어요.** 프로그램 이름을 그림처럼 보이게 하는 숨은 문자(실제 이름이 `Hoodie…exe`인 파일을 `Hoodie…jpg`로 보이게 하는 것)는 지워요.
- **스토어 버튼은 진짜 스토어로만 가요.** **Booth에서 열기** 버튼은 booth.pm만 열 수 있어서, 가짜 로그인 페이지로 바꿔치기할 수 없어요.
- **변조는 알아채요.** Hoard는 쓰는 모든 기록에 봉인을 해요. 다른 프로그램이 바꾸면 Hoard가 알려주고, 확인할 수 있게 사본을 남기며, 바뀐 링크는 믿지 않아요.
- **손상된 파일이 있어도 망가지지 않아요.** 확인할 수 있게 따로 두고, Hoard는 계속 동작해요.

**Hoard 자체**
- **같은 컴퓨터의 다른 사람은 Hoard를 바꿀 수 없어요.** 설치할 때 프로그램 파일은 내 계정만 바꿀 수 있게 해요.
- **설치하는 것은 확인을 거쳐요.** 모든 패키지를 미리 기록된 지문과 맞춰 보기 때문에, 변조된 것은 설치되지 않아요. 브라우저는 공식 배포처에서 정해진 버전으로 받아요.
- **릴리스는 공개적으로 빌드돼요.** GitHub가 소스 코드에서 바로 릴리스를 빌드하고 체크섬과 함께 공개해서, 다운로드한 파일이 진짜인지 확인할 수 있어요.
- **모든 변경은 릴리스 전에 자동으로 보안 테스트를 거쳐요.**

**내 개인정보**
- **개발자에게는 아무것도 보내지 않아요.** 계정도, 추적도, 분석도, 광고도 없어요. Hoard는 내가 쓰는 스토어와만 통신해요. 보관하는 것과 지우는 방법은 모두 [PRIVACY.md](PRIVACY.md)(영어)에 있어요.
- 새로고침, 로그인, 다운로드를 빼면 **오프라인에서도 돼요**.

**어떤 앱도 막을 수 없는 것**
- **이미 컴퓨터에 있는 악성 코드.** 나로 실행되는 바이러스는 나처럼 로그인된 스토어를 쓸 수 있어요. 컴퓨터를 최신으로 유지하고 검사하세요.
- **내 컴퓨터의 관리자 권한을 가진 사람.**
- **스토어 자체 웹사이트의 문제.**

**스스로 안전하게**
- Hoard는 사용자 폴더 안처럼 나만 쓰는 폴더에 두세요.
- Hoard의 앱 데이터 폴더(아래 참고)는 아무와도 공유하지 마세요. 로그인 정보가 들어 있어요.
- 문제 해결용 파일을 공유하기 전에 내용을 확인하세요. 무엇을 샀는지 보일 수 있어요.
- 새 버전이 나오면 업데이트하세요(**설정**, **업데이트**).

<a id="sign-ins"></a>
## 로그인 정보

스토어마다 Hoard 전용 브라우저 창(평소 브라우저가 아니에요)에서 한 번만 로그인해요. 라이브러리와 다운로드가 함께 쓰니까 로그인은 한 번이면 돼요. 스토어마다 폴더 하나씩, 여기에 보관돼요:

| Windows | macOS | Linux |
|---|---|---|
| `%LOCALAPPDATA%\Hoard\sign-ins` | `~/Library/Application Support/Hoard/sign-ins` | `~/.local/share/Hoard/sign-ins` |

- **macOS**에서는 Hoard 브라우저가 키체인을 써도 되는지 한 번 물어봐요. **항상 허용**을 고르세요.
- **Linux**에서는 보호를 위해 키링이 필요해요(GNOME Keyring, Secret Service를 켠 KeePassXC, 또는 KWallet). 없으면 Hoard가 로그인을 저장하지 않아요. NAS처럼 데스크톱이 없는 컴퓨터에서는 Hoard의 `config.json`에 `"allow_unprotected_signins": true`를 설정해 허용할 수 있어요. 그러면 로그인 정보는 내 사용자 계정만 읽을 수 있다는 것으로만 보호돼요.
- **로그아웃:** **스토어**에서 스토어 하나 또는 전부에 대해 할 수 있어요. 그 스토어의 상품은 라이브러리에서 빠지니까(다운로드한 파일은 남아요), 컴퓨터를 같이 써도 두 사람의 구매품이 섞이지 않아요.
- **이전 버전의 로그인 정보**(공유 폴더 하나, 또는 프로그램 옆의 `.browser-profile`)는 처음 실행할 때 자동으로 스토어마다 폴더로 나뉘고, 예전 사본은 지워져요.

**다운로드 폴더 하나를 컴퓨터 두 대에서 쓰려면**(NAS 등): 각 컴퓨터의 Hoard는 자기 키로 기록을 봉인해서, 상대의 변경을 확인되지 않은 것으로 보고 스토어 링크를 다시 가져와요. 폴더를 공유하려면 한 컴퓨터의 Hoard 앱 데이터 폴더에 있는 `integrity.key`를 다른 컴퓨터의 같은 곳에 복사하세요.

<a id="tags"></a>
## 태그

Hoard에는 두 종류의 태그가 있어요:

- **내 태그:** 직접 만들어서 상품에 붙이는 태그.
- **추천 태그:** 여러 상품 이름에 나오는 단어(`FoxyHoodie v2`라면 `foxy`와 `hoodie`). 의미 없는 단어와 버전 번호는 빠져요.

태그를 붙이는 방법:

- **상품 하나:** 상품을 열고 **태그** 아래에 태그를 입력하거나, 추천을 클릭해 추가하세요. 태그 옆의 ×로 뺄 수 있어요. 추가한 태그는 다른 스토어에서 가진 같은 상품의 모든 사본에도 붙어요.
- **여러 상품:** **선택**을 고르고 상품을 클릭한 뒤(제작자 등으로 거른 다음 **보이는 것 모두 선택**도 돼요), 태그를 입력하고 **태그 추가** 또는 **태그 빼기**를 고르세요.
- **태그 화면**(**태그** 버튼)에는 모든 태그와 추천이 나와요:
  - 추천을 **남기기**하면 그 단어가 이름에 들어간 모든 상품(나중에 살 것도 포함)에 붙는 내 태그가 돼요. **숨기기**하면 더 이상 추천되지 않아요.
  - 태그의 **이름 바꾸기**를 할 수 있어요. 이미 있는 태그 이름으로 바꾸면 둘이 하나로 합쳐져요.
  - **이름 일치**는 어떤 태그에든 이 자동 일치를 붙여요. **삭제**는 태그를 지워요.

태그는 Hoard의 비공개 앱 데이터 폴더(Windows에서는 `%LOCALAPPDATA%\Hoard\tags.json`)에 저장되고, 라이브러리와 다운로드가 함께 써요. 한쪽에서 태그를 붙이면 다른 쪽에서도 붙어 있어요. 사이드바에서 어떤 태그로든 거를 수 있고, 필터는 함께 쓸 수 있어요.

<a id="offline"></a>
## 오프라인

새로고침, 로그인, 다운로드를 빼면 인터넷 연결 없이도 쓸 수 있어요. 새로고침할 때마다 모든 상품 그림을 저장해서 라이브러리 전체와 검색, 그림이 오프라인에서도 되고, 글꼴도 앱에 들어 있어요. 스토어에 연결할 수 없으면 Hoard가 알려주고, 저장된 라이브러리와 다운로드는 그대로 둬요.

<a id="things-to-know"></a>
## 알아 두면 좋은 것

- Hoard는 비공식 도구이고, Booth(pixiv), Gumroad, Jinxxy, Payhip, itch.io와 제휴하거나 승인받지 않았어요. 내 계정의 구매품을 내 로그인으로 읽기만 해요.
- 스토어는 웹사이트를 바꿔요. 바뀌면 그 스토어 읽기가 업데이트될 때까지 동작하지 않을 수 있어요. Payhip은 이미 자동화된 브라우저를 확인해요. Hoard는 내 도움을 받아 이를 해결해요(확인을 마칠 수 있는 보이는 창, 또는 내 브라우저에서 저장한 페이지).
- 다운로드해도 에셋으로 할 수 있는 일은 바뀌지 않아요. 각 제작자의 라이선스와 각 스토어의 약관을 따르세요.

<a id="reporting"></a>
## 문제 신고와 기여

이슈와 토론은 한국어로 써도 괜찮아요.

- **버그와 문제:** 문제를 찾았다면 무엇을 했고 무슨 일이 일어났는지 적어서 [버그 신고](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=bug_report.yml)를 열어 주세요. 스토어가 제대로 읽히지 않으면 `Hoard.bat debug <스토어>` 또는 `Hoard.bat probe jinxxy`를 실행해 출력을 첨부해 주세요. 단, 먼저 내용을 확인하세요. 이 파일에는 구매품이, 스크린숏에는 계정 이름이 보일 수 있어요.
- **기능 요청:** 사용 흐름을 개선할 아이디어가 있다면 [기능 요청](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=feature_request.yml)을 열어 주세요.
- **새 스토어:** 다른 플랫폼도 지원했으면 한다면 [스토어 지원 요청](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=storefront_integration.yml)을 보내 주세요.
- **토론과 지원:** 일반적인 질문은 [Discussions](https://github.com/Soloflighter1010/Hoard-Asset-Manager/discussions)에 글을 올려 주세요.
- **번역:** 한국어 번역은 AI의 도움을 받아 만들었어요. 어색한 곳이 있으면 [번역 수정](https://github.com/Soloflighter1010/Hoard-Asset-Manager/issues/new?template=translation.yml)으로 알려 주세요. 번역은 `hoard/web/i18n/ko.json`에 있어요.
- **보안 문제:** [SECURITY.md](SECURITY.md)(영어)에 나온 방법으로 비공개로 신고해 주세요.

## AI로 제작

Hoard의 코드, 디자인, 문서 대부분은 관리자의 지시와 테스트를 거쳐 AI 어시스턴트(Anthropic의 Claude)가 작성했어요. 그게 나에게 무슨 의미인지는 [AI-DISCLOSURE.md](AI-DISCLOSURE.md)(영어)에서 설명해요. 일본어와 한국어 번역도 이 페이지를 포함해 AI의 도움을 받아 만들었어요. Hoard 자체는 AI를 쓰지 않고, 내 데이터가 AI로 가는 일도 없어요.
