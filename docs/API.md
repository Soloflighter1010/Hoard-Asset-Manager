# Local HTTP API

Generated by `python scripts/build_api_docs.py`; edit registrations in `hoard/api/`.

All API data needs this run's access key. Changing endpoints require JSON POST from loopback.
The two handshake endpoints use a one-time entry token or the private running-instance token.
Image/file prefixes also accept a key in the address because image elements cannot set headers.

Request fields are optional at the transport boundary; each handler validates its own operation.
Shared action handlers list the union of their fields. `any` denotes a JSON value whose accepted
shape depends on the action. Responses describe the top-level JSON type or media type; errors
are JSON objects with an `error` string. See the handler for action-specific fields and errors.
