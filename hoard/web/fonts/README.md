# Fonts

The typefaces Hoard's pages use, bundled so the pages look right without an internet connection.
All three are licensed under the SIL Open Font License 1.1; the license texts are next to the fonts.

| File | Typeface | Used for |
|---|---|---|
| `DelaGothicOne-Regular.woff2` | Dela Gothic One | Headings and item titles |
| `ZenMaruGothic-Medium.woff2`, `ZenMaruGothic-Bold.woff2` | Zen Maru Gothic | Everything else |
| `OpenDyslexic-Regular.woff2`, `OpenDyslexic-Bold.woff2` | OpenDyslexic | Everything, with **Font: OpenDyslexic** in Settings (Accessibility) |

Dela Gothic One and Zen Maru Gothic cover Japanese as well as Latin text, which is why the files are a few
megabytes. They're the original fonts from google/fonts, converted to WOFF2 without other changes. OpenDyslexic
(by Abbie Gonzalez, antijingoist/opendyslexic) is its Latin subset as Fontsource publishes it
(`@fontsource/opendyslexic` 5.3.0, OpenDyslexic 0.910.12); Japanese and Korean text keeps the fonts above.
